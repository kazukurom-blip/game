# PLAYTEST — 通しで遊ぶ検証（ボット）

> 「ルミナリア・クラシック」Unity 版の Core（`classic-unity/Core/`）を、自動で遊ぶボットで最初から通して遊んだ結果。
> ボットは `classic-unity/Tools/PlayBot/`。設計の目安は `classic/docs/STATS.md`（7 章・8 章）・`DESIGN.md`・`QUESTS.md`。
> 数値は 2026-10-07 の Core とデータ（全 306 スキル・234 マップ・286 クエスト・170 敵）で、種 20261007 の 1 回分（乱数でぶれる）。
> **2〜5 章は直す前の記録**。この結果を受けて強さを調整した後の検証は **8 章**（直した物・ボットの前と後）。

## 1. やり方

### 1-1. ボットの決まり

- **GameSession に渡すのは `PlayerInput`（キー）と、UI から呼ぶ操作だけ**。歩く・跳ぶ・↓跳び・縄・はしご・ポータル（↑）・攻撃・スキル（押しっぱなし）・薬（`ItemPressed`）・拾う・調べる（`InteractPressed`）はキー。話す・クエストを受ける/報告・買う/売る・AP/SP・装備・書・転職・倉庫・タクシー・乗り物・起き上がる・宿屋・製作・ペット・クイズに答える は UI の操作（`Talk`・`AcceptQuest`・`Buy` …）。位置・HP・Lv などを直接書き換えない（`Teleport` も使わない）。
- 読むのは画面に出ている物（自分と敵の位置・HP/MP・落ちている物・持ち物・クエストの数・お知らせ）とデータ（マップ・クエスト・店）。
- 決めたこと: 賢者の石のクイズは「このゲームを知っている人」として正解を選ぶ。実時間の 1 日 N 回（ボスの間・ダンジョン・日替わりの店）はゲームの中の時間で数える（`session.Clock` をゲームの時間にする。何十時間も続けて遊ぶため）。
- 2 次で選ぶ枝: 戦士 ファイター・魔法使い ファイアウィザード・弓使い ハンター・盗賊 アサシン・海賊 ブローラー。AP は主の能力値、副は決めた量＋**命中が足りない時は DEX**（MISS を見て振る人と同じ。3-3）。SP は攻撃 → 熟練 → 加速 → 魔力の盾 → パッシブ の順（前提のスキルは、その先のスキルの価値で上げる）。

### 1-3. 動かし方

```
cd classic-unity
dotnet run -c Release --project Tools/PlayBot -- --lines all --tier 4 --hours 200        # Lv1 から（5 系統を同時に）
dotnet run -c Release --project Tools/PlayBot -- --lines all --start 70 --tier 3 --hours 40  # 近道: Lv70 から 3 次転職まで
dotnet run -c Release --project Tools/PlayBot -- --lines thief --verbose --tracefight      # 考えたこと・空振りを全部ログに
LUMINA_LONG=1 dotnet test Tests/Lumina.Core.Tests.csproj --filter Category=Long             # 長いテスト（下の 6 章）
```

- 出力は `.build/playbot/`（`<系統>.log`・`<系統>.csv`（Lv ごとの時間）・`<系統>.md`・`summary.md`）。
- 速さ: Core の更新は 1 フレーム約 3〜10 μs。ゲームの中の 1 時間が約 1 秒（5 系統を同時に動かして 200 時間で 10〜20 分）。

### 1-4. 近道（3 次・4 次の検証用）

ボットが Lv1 から Lv70・120 まで遊ぶと何百時間もかかり、途中でお金と薬が尽きて止まる（3 章）。3 次・4 次の道（マップ・クエスト・試験・クイズ・ボス）が通るかは、**その段階まで育ったキャラを作って**そこから遊ばせて確かめた（`Bot.MakeCheckpoint`）。作り方: 島のチュートリアルは完了・Lv は `CharacterState.LevelUp`（本物の HP/MP の伸び・AP・SP）を 1 つずつ・AP/SP はボットと同じ振り方・1 次は `AdvanceJob`、2 次は試験の証を持たせて `AdvanceJob2`、3 次は数値だけ（`AdvanceTier`）・通ってきた転職のクエストは完了・お金は STATS.md 8 章の目安（Lv30 4 万・Lv70 150 万・Lv120 1,200 万）。直接いじるのは作る時だけで、そこからは同じボットが遊ぶ。近道では転職のクエストと、それに要る物のクエスト（闇の水晶の N-14）だけをする。

- ボットの稼ぎは目安の 1/3〜1/10。理由は撃破の数: 1 分あたり 2.2 体（戦士・最初の 40 時間）〜 0.3 体（盗賊・200 時間）で、目安（STATS.md 7-1 の 9〜13 体）の 1/4〜1/6。薬代は目安と同じくらいなので、**Lv20〜30 で薬代が稼ぎを上回り、お金と薬が尽きる**。

### 3-2. ずれの理由（ボットの記録から）

1. **薬が尽きると抜けられない**: 倒れた回数のほとんどは「薬 0」の時。薬が無いと町で休む（自然回復 5 秒ごと）→ 狩り場へ歩く途中で敵に何度も当たって倒れる → 町で HP 50% で起き上がる、をくり返す（時間の 30〜60% が休み）。倒れると経験値 10% を失うので Lv も上がらない。
2. **盗賊は投げ星が尽きると攻撃できない**: クローは投げ星が無いと攻撃できない（CORE.md 4-4。弓は弱い殴りができる）。お金も無いと投げ星を買えず、木の剣に持ち替えるが LUK の盗賊はほとんど削れない（1 撃 11）。Lv23 から 180 時間動けなかった。
3. **命中（STATS.md 2-3）と敵の回避の釣り合い**: 必要な命中 = 55 × 敵の回避 ÷ 15、敵の回避 ≒ Lv × 0.5。同じ Lv の敵に全部当てるには命中 ≒ Lv × 1.83 が要り、戦士・海賊（ナックル）は DEX ≒ Lv × 1.6 が要る。DEX を Lv÷3 しか振らないと、Lv120 の戦士（命中 124）は Lv110 の敵（回避 54、必要 198）に **約 25% しか当たらない**（近道の最初の検証で 73% が空振り）。ボットは MISS を見て DEX を足す振り方にした（1-1）。
4. **島から大陸、町から狩り場の間の敵**: Lv20 以上の歩く敵は追ってくる。狩り場へ行く途中で何度も当たり、押されて進めない。
5. **お金を払わないと出られない地域**: 雲の上（C）・おもちゃの町（T）などは乗り物（1,000〜3,000 ルド）でしか戻れない。お金が尽きるとその地域から出られず、その地域の敵が強いと倒れ続ける（ボットは運賃と薬代を残してから行くようにした）。
6. **魔法使いの MP**: 魔法使いの攻撃は MP の薬が前提。青ポーション（100 MP・200 ルド）は HP の薬（約 1 ルド/HP）の 2 倍の値段で、Lv20〜30 の稼ぎでは足りない。

### 3-3. 調整の案（→ 8 章で直した）

- **薬の値段か敵のお金**: Lv15〜40 の敵のお金を 1.5〜2 倍、または橙・白ポーション・青ポーションを 2/3 の値段に。稼ぎ ≥ 薬代 × 2 を目安に。
- **命中**: 敵の回避を Lv × 0.5 から Lv × 0.3 くらいに下げる（クラシックの敵に近い）、または必要な命中の 55 を 40 くらいに。今のままなら戦士・海賊の 2 次以降のパッシブで命中を足す。
- **弾切れ**: クロー・銃でも、弓と同じく弾が無い時は弱い殴り（武器係数 1.4）ができるようにする（詰まなくなる）。
- **戻れない地域**: 倒れて起き上がる町から本土（V）へ無料で戻る道（または起き上がる時に 1 回だけ無料の帰還の書）。
- **倒れた後**: 起き上がる HP を 50% → 100%（1 人用なので）、または町の宿屋を Lv30 まで無料に。
