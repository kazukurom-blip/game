# WALL CRUSHER ∞（壁ドカーン）

右側の巨大な壁を殴って壊し続ける、強化インフレ系のブラウザゲーム。PC とスマホ両対応。ビルド不要。

- 遊び方: `index.html` を開く（ローカルは `npx http-server wallcrusher -c-1` など）。
- 流れ: タップで壁を殴る → 金貨で強化（パンチ力・気功弾は 25 Lv ごとに ×2）→ 壁は時間で迫ってくる。時間切れで 1 つ前に押し返される → ステージ 15 から「転生」。強化は 0 に戻るが、**魂コア**（永久強化の通貨）と**永久アビリティ**（16 種から 3 枚の中で 1 つ選ぶ、重ねると Lv アップ）が手に入る。
- 10 ステージごとに BOSS 壁（体力 ×5）、10 の地域（レンガ・石・氷・鋼鉄・水晶・溶岩・黄金・ネオン・翡翠・虚無、以後 II, III… と周回）。
- フィーバー、会心・超会心、金のレンガ、連打、実績 47 個（1 つで全ダメージ +3%）、留守の間の金貨、セーブの書き出し/読み込み。
- 音は WebAudio で作る効果音と BGM（素材ファイルなし）。

## ファイル
- `core.js` — 計算（式・強化・転生・実績）。描画なし、Node でも動く。
- `game.js` — 描画（Canvas）・入力・音・板の UI。
- `index.html` — 画面の枠と見た目。

## 確かめ
- `node tests/unit.mjs` — core の小さな確かめ
- `node tests/balance.mjs 25` — 普通のプレイヤーが転生を重ねたときの進み方の試算
- `node tests/browser.mjs` — PC とスマホの大きさで実際に遊ぶ確かめ（写真は tests/shots/）
