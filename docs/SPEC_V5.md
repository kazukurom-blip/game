# SPEC v5：4次転職後の難しさ・第2ワールドの壁・ネオン・コア（専用の強化）

ユーザーの要望（2026-10-06）：

- 4次転職のあとから、難しさをある程度上げる。
  - 雑魚は倒せても、ボスは装備・潜在・強化をしっかりやっていないとかなり時間がかかる。
  - 目安：ふつうの育ち方で **約1時間**、強化しまくると **約20分**。
- 第2ワールドは強さを跳ね上げる。
  - ふつうに育てていたら、第2ワールドの **最初の2マップくらい** でしか雑魚を倒せない。
- そこで専用のクエストが出て、第2ワールドの敵が **1%** で落とす **専用の強化ポイント** が手に入る。
  - それで **追加スキル** と、**能力アップ（%上昇）** ができる。

2 つの担当が並行で作る。境目と共通の決まりをここに書く。

## 共通の決まり

### ネオン・フラグメント（専用の強化ポイントになるアイテム）

- アイテムの ID は `neon_fragment`、名前は「ネオン・フラグメント」。素材で、束ねられる。
- 落とす敵：
  - 第2ワールドの通常の敵は、どれも **1%** で 1 個。
  - 第2ワールドのボスは、確実に数個。数はシステム担当が決める（目安：地域のボス 5〜10 個、ラスボス 20 個）。
- 落ちるのは、専用クエスト `nc_01_awaken` を受けたあとだけ（それまでは落ちない）。

### ネオン・コア（強化の仕組み）

- セーブには `state.neonCore = { cores: { arkcity: 0, cyberwild: 0, abyss: 0, zenith: 0 }, stats: { <能力の key>: Lv }, skills: { <スキル ID>: Lv } }` の形で残す。
  - 古いセーブでは、空の値で作る（migrateState）。
- **地域のコア**：
  - 4 つの地域にコアが 1 つずつある。Lv0〜20。
  - フラグメントを使って上げる。必要な数は Lv が上がるほど増える。
  - その地域の専用クエストを終えると、そのコアを上げられるようになる。
  - コアの Lv 1 につき：
    - **ネオン適性 +10**
    - **能力ポイント +1**
    - 主のステータスが少し上がる
- **能力アップ（%）**：
  - 能力ポイントを振る。
  - 項目：攻撃力% / 最大HP% / 防御% / 会心ダメージ% / ボスダメージ% / 防御無視% / 経験値% / ドロップ率%。
  - 各項目に Lv の上限と 1 Lv の上がり幅がある。値はシステム担当が決め、強さ担当と合わせる。
- **追加スキル**：
  - フラグメントで覚えて、上げるスキル。
  - 6 系統それぞれに 2 つずつと、全員共通 3 つ。
  - 4 地域のコアの合計 Lv で解放する。
- **ネオン適性**（MapleStory のアーケインフォースに当たる）：
  - `neonForceOf(state)` → 数値。コアの Lv の合計 × 10 ＋ 追加スキルなどの分。
  - 第2ワールドの各マップには、必要な適性 `forceReq` がある。値は `src/data/forceReq.js` の `FORCE_REQ = { マップの ID: 数 }` に書く。無いマップは 0。
  - 第2ワールドのマップで、自分の適性 F と、そのマップの必要な適性 R を比べ、`forceMods(F, R)` で倍率を出す。
    - 返す値は `{ dealt, taken }`。dealt は与えるダメージの倍率、taken は受けるダメージの倍率。
    - R = 0 のときは `{ dealt: 1, taken: 1 }`。
    - それ以外は r = F / R として、次の値。

      | r | dealt | taken |
      |---|---|---|
      | 0 | 0.1 | 3 |
      | 0.5 | 0.4 | 2 |
      | 1 | 1 | 1 |
      | 1.5 以上 | 1.5 | 0.7 |

      - 表の点の間は直線でつなぐ。
  - `forceMods` は `src/systems/neonCore.js` に置き、combat の計算に入れる（システム担当）。
  - HUD・ステータス窓には、自分の適性とマップの必要な適性を出す（足りないと赤）。

### 専用のクエスト

- `nc_01_awaken`：アーク・シティで受ける。第2ワールドの最初の 2 マップを越えようとすると壁にぶつかる、という話。
  - 終えると、ネオン・コアの窓が開き、フラグメントが落ちるようになる。アーク・シティのコアも解放される。
- 地域ごとに、コアを解放するクエストを 1 つずつ置く（`nc_cyberwild` / `nc_abyss` / `nc_zenith`）。
- 置き方は今のクエストの書き方（`src/data/questsW2.js` と同じ形。新しいファイル `src/data/questsNeon.js`）に合わせる。

### 強さの目安（強さ担当が数値で合わせる）

**キャラの育ち方の 3 段階**（`tools/sim_balance.mjs` で使う）

| 段階 | 装備 | 潜在 | 強化 | ネオン・コア |
|---|---|---|---|---|
| ふつう | その Lv の店・ドロップの装備 | レア程度 | ★0〜5 | 第2ワールドでは、その時点で集まる分 |
| しっかり | ボスの装備 | エピック〜ユニーク | ★10〜15 | 多め |
| 強化しまくり | 一番良い装備 | レジェンダリー | ★20 以上 | 上限近く |

**4 次転職（Lv100）より後のボス**

- 対象：第1ワールドの Lv100 前後のボスと、第2ワールドの全ボス。
- 倒すのにかかる時間：
  - ふつう：約 60 分
  - しっかり：約 30〜40 分
  - 強化しまくり：約 20 分
- 長い戦いになるので、ボスの攻撃は、ポーションを使えば耐えられる強さにする（1 発で倒されない）。

**4 次転職より後のボスの落とし物**（ユーザーの追加の要望）
- 難しくなったボス（上の対象のボス）は、強い装備を確率で落とす。
  - **大当たり 3%**：とても強い武器・防具（そのボス専用。同じ Lv 帯で一番強い。極レア mythic）
  - **ふつうの当たり 10%**：強い武器・防具（同じ Lv 帯の店・雑魚の装備より明らかに強い。legendary 程度）
  - 1 回倒すごとに、大当たりの抽選と当たりの抽選をそれぞれ 1 回ずつ（武器・防具の部位はランダム。6 系統の武器種も出る）。
- 装備のデータは `src/data/items.js` の新しい区画「v5 ボス装備」に足す（強さ担当）。見た目は今ある look.style の色違い。
- 1 時間かかる戦いに見合う手ごたえになるよう、大当たりは qset の最強より少し上、当たりは qset と同じくらいを目安に。

**4 次転職より後の雑魚**

- ふつうでも倒せる。目安は主力スキル 3〜6 発。

**第2ワールドのマップごとの必要な適性（forceReq）**

- 最初の 2 マップ（`w2_arkcity_f1`・`w2_arkcity_f2`）は、ふつうでも雑魚を倒せる。
- それより先は、必要な適性が段々に上がる。コアを育てないと、与えるダメージが 0.1〜0.4 倍になり、倒せない。
  - 目安：アーク・シティの奥は 30〜60、サイバー・ワイルドは 60〜120、アビスは 120〜180、ゼニスは 180〜240。
  - フラグメントが 1% で落ちる前提で、地域を進む速さが遊べる範囲になること（1 地域のコアを必要な分まで上げるのに、数時間くらい）。

## 担当の境目

| 担当 | 主に触るファイル | 触らない |
|---|---|---|
| **システム担当**（ネオン・コア） | 新規：`src/systems/neonCore.js`・`src/data/neonCore.js`（コアの費用・能力の表・追加スキル）・`src/data/questsNeon.js`・ネオン・コアの窓（`src/ui/` に新しいファイル）<br>少し：`src/systems/combat.js`（forceMods と % 能力を入れる）・`src/systems/progression.js`（ステータス・migrateState）・`src/systems/skills.js`（追加スキル）・`src/data/items.js`（neon_fragment）・敵のドロップを足す所・`src/data/missions.js`（読み込みの区画）・HUD とメニューのボタン | 敵の HP・攻撃・防御の数値、`FORCE_REQ` の値 |
| **強さ担当** | `src/data/enemies.js`（強さの数値・ボスのドロップ。とくにボスと第2ワールド）・`src/data/items.js`（v5 ボス装備の区画だけ）・`src/data/forceReq.js`（`FORCE_REQ` の値。新規）・`src/data/balance.js`・`tools/sim_balance.mjs`・`docs/BALANCE_V5.md`・tests | ネオン・コアの仕組みのコード、クエスト、UI |

- `src/data/forceReq.js` は強さ担当のファイル。
  - システム担当は、自分の作業コピーで仮の中身（`export const FORCE_REQ = {};`）を置いてよい。
  - マージでは強さ担当の中身を使う。
- 強さ担当は、システム担当がまだ作っていない `neonForceOf` / `forceMods` / % 能力を、上の決まりどおりの式として `tools/sim_balance.mjs` の中で再現して計算する。
  - % 能力の値は仮の値でよい。目安：上限まで振ると攻撃力 +30%・ボスダメージ +40%・防御無視 +20% くらい。
  - マージのあとで、メインが実際の値と合わせる。
