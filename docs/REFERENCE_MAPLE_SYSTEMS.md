## 0. 要約（忙しい人向け）

- メイプルの強さは「**移動が気持ちいい**（フラッシュジャンプ/テレポ）」「**スキルが職ごとに強烈に個性的**」「**エンドコンテンツが段階的に無限に続く**（★強化・潜在・シンボル・ユニオン・HEXA）」の3点。
- メイプルの弱さは「**確率の不透明さ**（2024年に韓国公取委が過去最大の制裁金）」「**装備破壊のストレス**」「**毎日の義務的作業（シンボルデイリー・複数キャラ周回）**」「**課金前提の強化**」「**サブキャラ育成の強制（ユニオン/リンク）**」。
- 本作は「**全確率表示・天井つき・装備破壊なし・作業の持ち越し可能・オフラインで完結・2人のヒーローを育てる意味がある**」で上回る。
- 優先度Sは 8 機能: ①移動スキル＋共通スキル拡張 ②スキルLv/SP/マスターレベル/キー配置 ③ネオン・チューン（★強化・破壊なし）④チップ潜在（全確率公開・天井）⑤ボス難易度＋周回報酬 ⑥無限タワー ⑦クエストナビ ⑧ペットスキル（自動ポーション等）。詳細と数値は §3。

**2025〜2026 のトピック**
- KMS 2026夏「OVERDRIVE」: 新職業（直接攻撃を一切しない**召喚100%の職**）、第3のHEXAスキルコア、Lv280 新ボス、**ボスHP・制限時間の短縮によるプレイ時間削減**、1+1 レベルアップ（バーニング）を Lv280 まで。
- GMS 2026夏「Ride the Lightning」: 新職（聖なる光の槍を振るう近接STR職、グローバル独自）＋専用地域、既存職のリマスター、新エンドボス3体。前半6/17・後半7/22の2部構成。

### 1-3. バフ・パッシブの典型

| 名称（一般名） | 効果 | 典型数値（参考値） |
|---|---|---|
| ブースター | 攻撃速度 +2段階（バフ、長時間 or 常時） | 持続 200〜300秒、後に常時化 |
| マスタリー | 武器熟練度（最低ダメージの底上げ）、命中、攻撃力 | 熟練度 50%→70%→（4次で）80〜90% |
| ファイナルアタック | 攻撃スキル命中時に確率で追加攻撃 | 発動 40〜60%、威力 100〜200% |
| 職固有バフ | 攻撃力+%、クリ率、ダメージ+%、HP+% | 持続 180〜300秒 |
| 召喚 | 一定時間自動攻撃するオブジェクト | 持続 30〜260秒 |
| バインド（5次共通） | ボスを数秒拘束、拘束中は被ダメ増 | CT 120〜180秒 |
| 全体バフ（4〜5次） | 大技バフ（ダメージ+%）を短時間、CT 120秒前後 | いわゆる「バースト」 |
| ハイパーパッシブ | 「スキルAダメージ+20%」「スキルAの攻撃対象+1」「ボス攻撃時ダメージ+20%」を点数で選ぶ | 合計 15 点程度を Lv140〜で配分 |

**スキル設計の型**
1. **狩り（モブ）用**: 広範囲・多段・低CT、移動しながら撃てる。
2. **ボス用**: 単体高倍率、CT付きの大技、バーストバフで「120秒周期」に火力を集中。
3. **補助**: 移動、バフ、回復、無敵、バインド。
4. **職の個性ゲージ**: 例として「攻撃で溜まる→解放で変身」「HPを消費して攻撃」「2つの形態を交代（2キャラのタッグ）」「召喚のみで戦う」「コンボ数で強化」など。**本作の2ヒーロー＆4系統に最も応用すべき部分**。

### 1-4. スキルLv・SP・マスターレベル
- レベルアップごとに **SP 3〜4**（転職段階ごとに別プール。1次のSPは1次スキルにしか使えない）。転職時にボーナスSP。
- 各スキルに **最大Lv（10/20/30）** と **マスターレベル**（現在上げられる上限）。旧仕様では4次スキルのマスターLvが「マスタリーブック」で 10→20→30 と解放された（現行KMSでは撤廃・簡略化の方向）。
- **前提スキル**（Aを Lv5 にしないとBが習得不可）でツリー感を作る。
- 現行では「スキル初期化（SPリセット）」が無料/安価になり、**SP振りミスのストレスはほぼ撤廃**された。
- 5次以降は SP でなく素材（エルダ・ソルエルダ）でコアLvを上げる＝**レベル以外の成長軸**。

### 1-5. キー配置
- 全キーボードに**スキル・アイテム・UI・ペット餌・感情表現**を自由にドラッグ配置（キー設定ウィンドウ）。複数のプリセットを保存可能（狩り用/ボス用）。
- **クイックスロット**（画面右下に表示されるショートカット枠）。
- 補助: 「スキルコマンド」（↓→+攻撃 で発動する職）、スキルの「自動発動ON/OFF」（バフを自動で掛け直す設定、5次以降の一部）。

- 補助ルール: 「スターキャッチ」（動く星をタイミングで止めると成功率が乗算で上がるミニゲーム。KMS/MSEA では撤廃し基本確率に内包、GMS は継続との報告）、**破壊防止**（コスト倍で破壊なし、★15〜17程度まで）、**イベント**（★5/10/15で100%成功、費用30%OFF、★21以下の破壊率30%減 等）。

- 費用はメル（ゲーム内通貨）で、★と装備Lvに応じて**指数的に増える**。高★ほど「破壊→やり直し」の期待費用が膨大。

### 2-2. 潜在能力（キューブ）とアディショナル潜在
- 装備に **3行の潜在オプション**。等級: レア → エピック → ユニーク → レジェンダリー。
- キューブで**再設定（リロール）**。再設定のたびに等級が上がる確率（ランクアップ）がある。上位キューブは「再設定前と後を選べる」「2段階ランクアップ」機能。
- 1行目は等級相当の値、2・3行目は一定確率で同等級（=「上級行」）、外れると1段下の値。
- **アディショナル潜在**（別枠3行・別キューブ）。
- 2021〜2024年の流れ: KMS で確率の公開→**天井**（一定回数でランクアップ確定）導入→ 2024年 **韓国公正取引委員会がキューブの確率操作・不告知で約116億ウォン（約8.8百万USD）の制裁金**（電子商取引法違反として過去最大）→ **キャッシュショップでのキューブ販売終了、メル（ゲーム内通貨）での潜在再設定へ移行**（KMS 2024年1月発表）。GMS では「Glowing/Bright Cube」等の新キューブへ整理。
- 教訓: **確率の透明性はプレイヤーの信頼そのもの**。本作は全確率・試行履歴・天井をUIに表示する（§3 S-4）。

### 2-3. 追加オプション（フレイム / 追加オプション）
- 装備ドロップ時にランダムで最大4行の追加ステ（主ステ、攻撃力、ボスダメ、全ステ%、着用Lv減少等）。段階（1〜7段階）でランダム。
- 「再誕の炎」で再抽選。ボス装備は高段階が出やすい。→ 本作では「カスタムパーツ」として B 優先度。

### 2-4. シンボル（アーケイン / オーセンティック / グランドオーセンティック）
- Lv200以降の地域ごとに**シンボル装備**。地域デイリークエスト・ドロップでシンボル素材を集め、レベルを上げる（アーケイン最大Lv20、オーセンティック最大Lv11、2024年以降グランドオーセンティックも）。
- 効果: 主ステ固定値UP＋**「アーケインフォース(ARC)/オーセンティックフォース(AUT)」**。地域の敵は要求値を持ち、**不足するとダメージが大幅に下がる**（逆に超過で与ダメ増）。
- 必要数（参考値）: Lv n→n+1 で `n² + 11` 個（アーケイン）。最大まで約2,679個 → 毎日20個前後で数か月。
- 不満点: **毎日の地域デイリー×複数キャラ**の義務感、サブキャラでもう一度最初から、が代表的な不満として挙がる。

### 2-5. ユニオン（GMS: レギオン）
- **アカウント内の全キャラLv合計**でユニオン等級が上がる。キャラごとに「職ごとの効果（攻撃隊員効果: 例 クリ率+%、ボスダメ+%、経験値+%）」があり、**グリッド盤面にキャラのブロック（Lvで形が大きくなる）を配置**→ 盤面の外周エリアのステータス（主ステ、クリダメ、防御無視等）が上がる。
- ユニオンレイド: 配置したキャラが自動で攻撃し「ユニオンコイン」獲得 → **ユニオンアーティファクト**（コインで強化する追加ステ）。
- 2025「ユニオンチャンピオン」: Lv260以上かつユニオン8000以上で解放。指定したチャンピオン（主力サブキャラ）の育成度で全チャンピオンにステータス付与＋「チャンピオンレイド」。
- 意図: サブキャラ育成の動機付け。副作用: **「サブキャラを何十体も育てる作業」が前提化**。

### 2-7. デイリー/ウィークリーボス、難易度、ボス結晶
- 各ボスに **イージー/ノーマル/ハード/カオス/エクストリーム**。難易度で HP・攻撃・**デスカウント**（復活回数、1〜5）・**制限時間**・ギミックが変わる。上位難易度は前段階クリアや入場Lvが条件。
- 入場制限: デイリーボスは1日1回、ウィークリーボスは週1回、一部は月1回。
- **ボス結晶**: 撃破で入手しNPCに売却してメル化（=主要な金策）。**1キャラ週14個・ワールド週180個**（従来値・参考）という上限で「複数キャラ周回（いわゆる結晶キャラ）」が発生。
- 2026: KMS「OVERDRIVE」で一部ボスの HP・制限時間を減らし**プレイ時間削減**。
- ボス固有ドロップ（極レア装備＝通称「漆黒」）と、ボス撃破の**初回クリア実績・称号**が強いモチベーション。

### 4-6. 収集要素のフレーバーテキスト方針
- **長さ**: 1〜2文（40〜80字）。図鑑は「生態」＋「街の噂」の2行構成。
- **トーン**: 陽気・皮肉・少しだけ切ない（GTA的風刺×メイプル的ほのぼの）。実在ブランド・実在人物のパロディはしない。
- **3層構造**: ①表（誰でも分かる説明）②裏（撃破数50で解放される小ネタ）③真相（撃破数100 or ボス撃破で解放、世界の謎に触れる一文）。
- **相互参照**: 図鑑・アイテム説明・SNS投稿・NPC台詞で**同じ噂を別視点から**語る（例: 「沖の光」を、漁師は“お化け”、博士は“未確認物体”、SNSは“#UFO”、ゾグの図鑑は“同胞の灯台”）。
- 例:
  - ネオンゼリー（図鑑）: 「蛍光ドリンクの空き缶に住む。夜になると勝手に光る。」／裏: 「キングゼリーの“子分”を名乗るが、本人は知らない。」
  - ★25到達の装備称号: 「ネオン管の芯まで調律された一品。触ると少しだけ音がする。」
  - スパイア100階の称号: 「タワーの地下に、タワーより高い塔がある。誰が建てた？」

## 5. 実装担当への引き継ぎメモ（優先度S のデータ設計案）
- `state` 追加案（progression.newState / migrateState で初期化）:
  - `state.skills` は既存。追加 `state.sp = {t0, t1, t2, t3, t4}`、`state.keymap = {preset:0, presets:[{...},{...}]}`
  - `item.star`（0〜25）、`item.tunePity`（連続失敗数）
  - `item.pot = {grade:'rare'|'epic'|'legendary'|'mythic', lines:[{key, val}], pity:{up:0}}`、`item.potRevealed`
  - `state.boss = {[bossId]: {normal:{last:ts, clears:n}, hard:{...}, chaos:{...}}}`、`state.trophies = n`
  - `state.spire = {best:0, weekBest:0, weekKey:'2026-W40', checkpoint:0, firstClears:{}}`
  - `state.pets = {[petId]: {aff:0, lv:1, skills:[...], potThresholdHp:50, potThresholdMp:30, autoBuff:null, filter:'common'}}`
  - `state.questNav = {freeMovesToday:5, day:'2026-10-04'}`
- 日付リセットはローカル時計（`Date`）基準、月曜 5:00 週リセット。時計巻き戻しは「最後に記録した時刻より前なら加算しない」程度の簡易対策で十分（オフライン1人用なので厳密さより快適さ）。
- 乱数: 強化/潜在はシード付きRNG（`state.rngSeed`）で再現可能にし、テスト（`npm run test:unit`）で成功率・天井の統計テストを書けるようにする（10万回試行で表の±1%以内、天井で必ず成功）。
- 確率表示UI: 強化ウィンドウ・潜在ウィンドウに「確率」「天井残り」「期待回数」を常時表示。
