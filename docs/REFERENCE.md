# NEON VICE STORY — リファレンス調査レポート

調査日: 2026-10-03 / 担当: リファレンス調査担当
対象: GTA6（Grand Theft Auto VI）と メイプルストーリー（MapleStory）の公開情報・ゲームデザイン要素の分析、および本作への落とし込み指針。

> ## ⚠ 著作権・商標についての明記
> - 本作「NEON VICE STORY」は**完全オリジナルの架空作品**です。舞台は架空の **「ネオリダ州 / ヴァイス・ベイ市」**。
> - GTA6 の「レオニダ州」「ヴァイスシティ」「ジェイソン」「ルシア」、メイプルストーリーの「キノコ/スライムの固有デザイン」「メイプルリーフ」等の**名称・ロゴ・固有キャラ・UIグラフィックの再現は禁止**。参考にするのは「雰囲気」と「ゲームデザインの仕組み」のみ。
> - 画像ファイルはダウンロード・保存していません。全グラフィックはコードによる手続き描画で、独自デザインにすること。
> - 本作の敵 `slime` / `mushroom` は**一般的なファンタジーモチーフとして独自形状**（例: スライム=ネオン色ゼリーにサングラス、マッシュルーム=ネオン傘の毒キノコ）で描き、メイプルの「オレンジキノコ」「スライム」に似せないこと。

### 1-2. Extended Look / 報道で語られたゲームプレイ（※一部はリーク由来・未確定を含む）
- **手配度は★6段階**に復活。
- 犯罪は**NPCの目撃や警報で初めて通報**される。
- **中抜き（空洞）の★＝警察は捜索中だが人相が割れていない**状態。
- 警察が把握している特徴を HUD の3アイコンで表示（**服／顔／車両**）。髪型・全身着替えで特徴がリセット、サングラスや帽子だけでは不十分 → 車のトランクに着替えを積む仕組み。
- 警官はミニマップの赤点で常時表示されず、**画面端の赤×青の柔らかいフラッシュ**で追跡感を伝える。
- 車上荒らしはロックピック・ミニゲーム化。ジムでの筋トレ/体型変化。2人がスマホのチャットで会話。
- HUD は GTA5 より**ミニマルで素早い**印象。
- SNS 風の縦動画・配信・ミーム文化（トレーラーで多用された「スマホ縦撮り映像」「ライブ配信UI」）が世界観演出の柱。

### 1-3. ビジュアル分析（本作へ翻訳すべき「雰囲気」）
- **時間帯**: ゴールデンアワー〜夕焼け〜ネオンの夜。空は「オレンジ→ピンク→パープル」の縦グラデ。
- **色**: 夕焼けピンク、マンゴーオレンジ、ターコイズ/ティールの海、マゼンタ〜パープルのネオン、ヤシのシルエット（ほぼ黒紫）。
- **モチーフ**: ヤシ並木、アールデコのホテル、ビーチ、モーテル看板、ボート、スポーツカー、湿地のワニ、フラミンゴ、ストリップモール、ハリケーン/スコール、マイアミ風パステル建築。
- **トーン**: 陽気・派手・風刺的（SNS・ワイドショー的な誇張）。犯罪×リゾートのギャップ。
- **HUD要素**: ミニマップ（左下）、所持金（右上・緑系数字）、手配★、武器アイコン、スマホUI、ミッション目的テキスト（画面下中央の字幕）。

### 3-2. 全面採用リスト

**ゲームメカニクス**
1. メイプル式の多段一方通行足場・ロープ・↑で入るポータル。
2. 敵の自動リスポーン（上限・間隔）による狩り場ループ。
3. 経験値→Lv→AP(STR/DEX/INT/LUK)/SP 振り、スキル4枠＋ポーション2枠。
4. レア度5段階のドロップと、拾うまでのワクワク（跳ねる・光柱・バナー）。
5. 装備がそのまま見た目に反映（ペーパードール）。HP減少で服が破れる（インナーは必ず残る全年齢表現）。
6. GTA式手配度★: 犯罪で heat 上昇→警官/SWAT/パトカー出現、逃げ切りで減衰。**空洞★（捜索中）→塗り★（追跡中）**の2段表現を推奨。
7. 車の乗り降り（E）、高速移動・轢き（手配度上昇）。
8. NPC からのクエスト（！/？）、2人組がのし上がるクライムストーリー＋デイリー。
9. 警察が近いときの**画面端の赤/青フラッシュ**（GTA6 由来の演出、ミニマップ赤点の代わり）。

**UI**
1. 左下: メイプル風の Lv バッジ＋名前＋HP(赤)/MP(青)/EXP(黄)バー（角丸・縁取り・グロス）。
2. 右上: GTA風所持金（`$` 緑白の太字、影付き）と ★×5（金色、空洞は白縁のみ）。
3. 左上: ミニマップ（足場・ロープ・ポータル・NPC・プレイヤー点）。
4. 下中央〜右下: スキルバー（クールダウンは時計回りの暗幕＋残秒数）。
5. 右側: クエストトラッカー（半透明黒パネル、達成で黄緑）。
6. 通知トースト（上中央）、レアドロップバナー（レア色の帯＋光沢スイープ）。
7. ウィンドウ類はメイプル風の角丸パネル（濃紺半透明＋ネオンピンク/ティールの縁）。
8. SNS風演出: レベルアップやボス撃破時に「♥ 1.2K」「#ViceBay」のような**架空SNS風ポップ**（実在アプリ名・ロゴは使わない）。

**アート方向性**
1. 背景は常に夕焼け〜ネオン夜の縦グラデ＋パララックス（遠景ビル→中景ネオン看板→近景ヤシ）。
2. キャラは2.5頭身ちびアニメ、太いアウトライン、大きな瞳ハイライト。
3. エフェクトは加算合成で発光、ピンク/ティール/ゴールドを基調。
4. ダメージ数字は太い縁取り（黒紫 #2A0B3D）＋グラデ塗り、多段は縦に積む。
5. 80年代レトロ（シンセウェイブ）×現代スポーツカー。

## 4. アニメ調キャラデザイン指針（Canvas 手続き描画用）

### 4-1. 基本比率（見た目の高さ 80px 基準、足元中央 `(x,y)`）
| 部位 | 寸法目安 | 備考 |
|---|---|---|
| 頭（顔円） | 幅 34〜36px、高さ 32px（横長気味の楕円） | 全身の約40%。頭頂は `y-80`、顔中心 `y-62` |
| 胴体 | 幅 20px、高さ 20px（台形、肩幅＞腰幅） | 胴上端 `y-44` |
| 腕 | 長さ 16px、太さ 6px（先端に直径6pxの手） | 肩から振り子回転 |
| 脚 | 長さ 18px、太さ 7px、靴は 10×6px | 歩行は ±25° の振り子 + 上下バウンス 1〜2px |
| 頭身 | 約2.5頭身 | 頭:胴+脚 ≒ 1:1.5 |

- **アウトライン**: 2〜2.5px、純黒ではなく**濃い紫黒 `#2A1430`**（色が濁らず、ネオン背景で映える）。`lineJoin='round'`。
- **影（セル）**: 塗り色を約15%暗くした色で、光源左上→右下側にベタ影1段。
- **地面の影**: 足元に `rgba(20,0,30,0.3)` の楕円（幅24×高6）。

### 4-2. 顔パーツ
- **目**: 顔の下半分に配置（顔中心よりやや下＝幼く見える）。片目 幅 7px × 高さ 9px の縦長楕円、目の間隔 10px。
  - 構造: ①白目は省略可 → ②虹彩（`eyeColor`、上を暗く下を明るく縦グラデ）→ ③瞳孔（虹彩の60%、濃色）→ ④**ハイライト大**（直径3px白、右上）→ ⑤**ハイライト小**（直径1.5px白、左下）→ ⑥上まつ毛ライン 2.5px（外端を少し跳ね上げ）。
  - 瞬き: 3〜5秒ごとに 0.12秒、目を高さ1pxの線に。
  - 被ダメ時: `> <` 形、勝利/レベルアップ時: `^ ^` 形。
- **頬の赤み**: 目の外側下に楕円（幅6×高3）`rgba(255,110,150,0.45)`、上に斜線2本（白 40%）を足すとさらにアニメ的。
- **口**: 小さく（幅3〜4px）。通常は「ω」や小さい弧、攻撃時は開いた三角（中 `#C2304A`）。
- **鼻**: 省略するか、1px の点のみ。
- **眉**: 細い弧。強気キャラは内側を下げる（ルナ）、クール系は水平〜わずかに下げ（ジン）。

### 4-3. 髪
- 髪は**頭より一回り大きい**シルエット（前髪で顔の上1/3を覆う）。後ろ髪→顔→前髪の3レイヤー順で描画。
- **ハイライト**: 頭頂付近に「天使の輪」型の弧帯（幅は髪の20%、髪色を明るく+白30%）、または三日月形2〜3個。
- 毛先は尖ったベジェで束感（3〜5束）。歩行・ジャンプで毛先/ツインテを `sin(t)` 揺れ（遅延追従）。
- 髪の影色は髪色を暗く＋少し紫寄りに（例: ピンク髪の影は赤紫）。

### 4-5. 敵・NPC への応用
- モンスターは**丸いシルエット＋大きな目＋頬の赤み**で「かわいい」側、ギャング/警官は同じちび体型に**サングラス・眉の角度**で「かっこいい/悪そう」側を表現。
- 警官は紺 `#1F3A8A` ＋ 金バッジ `#FFD23F`、パトランプは赤 `#FF2E4D` / 青 `#2E7BFF` 交互。
- ボスは1.6〜2倍スケール＋オーラ（加算合成の輪郭グロー）。

### 4-7. ダメージ数字
- フォント: `bold 28px "Arial Black", sans-serif`（クリ 34px）。`strokeText` 5px `#2A0B3D` → `fillText` 縦グラデ。
- 通常: `#FFE36E` → `#FF8A1F`、クリ: `#FF7AD9` → `#C2187A` ＋左上に星、被ダメ: `#D9B3FF` → `#8A3DF0`、回復: `#B8FF9E` → `#2ECC71`、MISS: `#CCCCCC`。
- 動き: 出現時 1.4倍→1.0倍のポップ（0.1秒）、0.8秒かけて 40px 上昇しつつ後半でフェード。多段は 1ヒットごとに 26px 上へ積む。
