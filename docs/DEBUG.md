## デバッグパネル（`src/debug/debug.js`）

| キー | 操作 | キー | 操作 |
|---|---|---|---|
| F3 | 当たり判定 | Shift+F3 | 全アイテム付与 |
| F4 | 無敵 | Shift+F4 | お金+10000 |
| F5 | Lv+1 | Shift+F5 / F6 | 手配度 ±1（警察は町のみ） |
| F6 | HP-10%（服破れ確認。**v3: 自然回復と PET の自動ポーションを止める**） | Shift+F7 | HP/MP 全快 |
| F7 | そのマップの敵をスポーン | Shift+F8 | インベントリ整理 |

| F10 | ミッション即完了 | ボタン | 時刻 朝/昼/夕/夜 |

コンソール / テストから: `game.debug.run('<id>')`、`game.debug.setLevel(100)`、`game.debug.warp('casino')`、`game.debug.spawnEnemy('boss_don')`、`game.debug.setClock(22)`、`game.debug.givePet()`。
性能調査: `game.debug.skip = {bg:1, tiles:1, ents:1, night:1, hud:1}` で描画レイヤーを止める。**v3 追加: `game.debug.profile = true` の間、`game.perf.phases` にフレーム内の部位別処理時間（u.player / u.enemies / u.fx / bg / tiles / ents / player / fx / night / flash(カットイン・コンボ) / hud / ui / screenFx / save, ms）が入る**（スパイクの原因調査用）。
テスト用: `game._titleQuick = {slot, create:{classId, name, gender}}` でタイトルを飛ばして開始。`(await import('./src/ui/title.js'))._titleState()` でタイトル画面の状態。

## 未解決の問題

10回の上限に達した問題はありません。以下は直し切れていない（試行3回で打ち切り、方針の判断が必要な）ものです。

- **大技連発時の単発スパイク（headless で 16〜22ms が 1500 フレームに 1〜3 回）**: 症状は上の #7。部位別タイマーで見ると、スパイクは背景・敵の描画・HUD・カットインなど**毎回違う部位**に出て、V8 の GC（トレースでメジャーGC 最大 9.6ms・計29回/1200フレーム）とは重なっていないフレームもある。原因の推測: headless chromium のソフトウェア描画では Canvas2D の描画命令が溜まると途中でまとめてラスタライズされ、その時間がたまたま実行中の部位に乗る（GPU のある通常ブラウザでは別プロセスで処理される）。試したこと: ①〜⑥（上表）。残りの手としては、敵のベクター描画のスプライトキャッシュ化（敵の種類×向き×アニメのコマ）、毎フレームのオブジェクト生成（`{...}` / 配列）の削減による GC 回数の削減、背景の色調済みレイヤーのキャッシュ（v2 からの提案）があり、どれもアート担当の範囲の大きめの改修です。

## 残課題・気づいた点（提案）

- **★強化の成功演出が二重**: 強化窓の中の「SUCCESS! ★n に強化！」と、画面全体のエフェクト（星が弾ける「★n SUCCESS!」）が同時に出て、1秒ほど成功率・天井の表示に重なる。どちらか一方（窓の中だけ）にすると見やすい。
- **町では「町ではスキル不可」がスキルバー中央に常時表示**され、D〜H の枠に重なる（仕様どおりだが、枠の上ではなく上側の帯に出すと枠が見える）。
- **潜在（レア）の再設定で同じオプションが並ぶ**ことがある（例: 2・3行目が両方「被弾時5%でHP回復+2%」）。メイプル式なら仕様どおりだが、重複不可にするか確率表に明記すると親切。
- **ログボの通算日数**: 新規キャラでは初日分が自動で受け取られるため、窓を開くと既に「受け取り済み」。初回だけ窓を開いて受け取る演出があると分かりやすい。
- **アリーナ/タワー/ボス部屋の HUD**: 左上に「FIELD 推奨 Lv…」と出る（インスタンスなので「TOWER 3F」「ARENA WAVE 2」などの表示にすると良い）。
- v2 からの継続: 夕方・夜の全画面合成の負荷（GPU 側）、ボスの硬さのバランス、デバッグパネルとトラッカーの重なり（デバッグ用なので許容）。
