# NEON VICE STORY — v3 仕様（転職・ナビ・移動スキル・エンドレスコンテンツ）

前提: ARCHITECTURE.md / SPEC_V2.md / SPEC_JOB.md は有効。目標は**メイプルストーリーを参考にしつつ、作り込み・設定・遊びやすさで上回る**こと。詳細な調査は docs/REFERENCE_MAPLE_SYSTEMS.md（リサーチ担当）。

## 1. クエストナビ（UI＋システム）
- ミッション窓（J）でクエストをクリック → 詳細パネル: 目的ごとに**対象マップ名（Lv帯）**、**対象NPCの名前と居る町**、対象の敵/アイテム名、現在の進捗。
- 「ワールドマップで表示」ボタン → ワールドマップ（M）で対象マップ/NPCの町を点滅表示し、**現在地からの最短ルート**を線で強調（WORLD_GRAPH の BFS）。未訪問マップでもクエスト対象なら名前を表示してよい。
- HUD のクエストトラッカーの項目クリックでも同じ詳細を開く。
- **ナビ矢印**（メイプル以上の便利機能）: 追跡中クエストの対象が別マップのとき、画面端に「次に進むポータル」の方向と行き先名の矢印。同じマップならNPC/敵の方向。
- システム側 API: `missionGuide(game, missionId)` → `[{objIndex, text, mapId, mapName, npcId?, npcName?, targetName?, route:[mapId...], nextPortal:{x, y, to}}]`。

## 2. 会話キー V
- 入力 `talk` = **V**（core/input.js 追加済み）。NPC に近づく（約90px）と頭上に「V で話す」表示。V で会話。E/Enter は従来どおり（車の乗降・決定）だが、NPC 会話は V を正式な操作として案内。

## 3. スキル拡張（メイプル準拠）
- スキルバー **8枠**: A S D F ＋ Q W G H（`skill5..8` 追加済み）。state.skillBar を8要素に。
- 移動スキル: Lv1 から「ストリートダッシュ」（移動速度+20〜30% バフ・低MP）。2次で系統別の移動アクション（フラッシュジャンプ／テレポート／ラッシュ／グライド。kind:'move'）。3次で2次移動スキルの強化（enhances）。物理は player.js `doMoveSkill(skill, lv)`。
- 職ごとに アクティブ攻撃・バフ・パッシブ・ブースター・マスタリー・最終奥義 を揃える（SPEC_JOB 参照）。

## 4. エンドレス／やり込みコンテンツ（優先度はリサーチ結果で確定）
候補（キーは U=コンテンツ窓, O=実績窓。追加済み）:
- **無限ネオンタワー**: 階層ごとに敵が強化、10階ごとにボス、最高到達階の記録と報酬、週替わり特性。
- **装備強化「ネオンチューン」**（スターフォース相当）: +1〜+25、成功率表は**常に画面に表示**（確率の透明性）、失敗時の破壊なし（代わりに段階ダウン or 天井システム）。
- **潜在能力「ハックチップ」**（キューブ相当）: レア/エピック/ユニーク/レジェンダリー等級、オプション抽選、等級アップの天井。
- **デイリー/ウィークリーボス**（難易度ノーマル/ハード/カオス）とボスの戦利品。
- **ネオンアリーナ**（モンスターパーク相当）: 時間制ウェーブ、経験値ボーナス、1日回数制限。
- **実績**＋称号コレクション、**ログインボーナス**、**シンボル的な地域成長**（地域ごとのレベル上げで能力上昇）など。
- 世界観の作り込み: 勢力、町の文化、NPCの背景、図鑑のフレーバーテキスト。

## 5. 本家（メイプルストーリー）を上回るポイント
各担当は以下を実装目標とする。メイプルの既知の不満点（REFERENCE_MAPLE_SYSTEMS.md §3）の裏返しと、ブラウザ1人用ならではの強みを狙う。

### スキル演出（アート＋サウンド）
- **ヒットストップ＆カメラ演出**: 大技でヒットストップ（0.04〜0.12秒）、ズーム、画面揺れ、色収差フラッシュ。メイプルにない「手応え」。
- **カットイン**: 4次奥義・転職時にキャラのアニメ調カットイン（顔アップ＋決めゼリフ＋職カラーの背景）。装備・見た目・性別を反映。
- **装備・職で変わるエフェクト**: 武器のレア度や★強化段階でスキルの色・軌跡・パーティクルが変化（★15以上で残光、ミシックで虹）。
- **コンボ演出**: 連続ヒット数カウンター＋段階的に派手になるダメージ数字、コンボ維持で小バフ。
- **手配度連動の演出**: ★が上がるほどBGMが緊迫化、スキルにネオンの残像。
- **画面の見やすさ設定**: エフェクトの濃さ（100/50/最小）、ダメージ数字のまとめ表示。本家の「エフェクトで何も見えない」問題を解消。

### 遊びやすさ（UI＋システム）
- **確率完全公開＋天井**（強化・潜在・ドロップ率も図鑑で確認可）。装備は壊れない。
- **クエストナビ**: 画面端の方向矢印、最短ルート、ワンボタン移動。
- **やり忘れ救済**: デイリー/ウィークリーは2周期まで持ち越し。
- **スキルのプレビュー**: スキル窓で実際の動きをミニ再生。
- **ビルド保存**: スキルバー・装備セットを2つ保存して切替（狩り/ボス）。
- **キャラ間共有**: 倉庫・図鑑・実績・一部ボーナスをスロット間で共有（サブキャラ強制ではなく「育てるとお得」）。
- **リプレイの記録**: ボス撃破時の最大ダメージ・クリアタイムの記録、自己ベスト更新演出。

### 世界・物語（GTAとの融合で本家にないもの）
- **手配度・車・ラジオ・SNS** がRPGと噛み合う（警察の追跡が町の緊張感になる、SNSのフォロワーで称号）。
- **昼夜で変わる町**: 夜だけ開く店・夜限定の敵・夜のクエスト。
- **NPCの日常**: 時間帯でNPCが移動・セリフが変化。
- **選択肢のあるストーリー**: 一部ミッションで選択（警察に協力 / ギャングに付く）→ セリフ・報酬・称号が変わる。
- **フレーバーの作り込み**: 全モンスター・全装備に説明文、町ごとの歴史、新聞（スマホ）で世界のニュースが進行に合わせて更新。
