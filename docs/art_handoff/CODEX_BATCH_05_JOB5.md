# Codex への依頼（第5弾）: 5次転職のスキルアイコン

**作業の続け方:**
- 第3弾（`CODEX_BATCH_03.md`）の「⑮ スキルアイコン」と同じやり方です。
- 下の表を上から順に描いて、1つの ZIP で納品してください。
- 自分で確認（大きさ・正方形いっぱい・文字なし）して合格したら、こちらの返事を待たずに納品してください。

**共通:**
- 保存先は `assets/sprites/` の下、表のファイル名のとおりです（`icons/skill/<スキルID>.png`）。
- 大きさは 256×256。正方形いっぱいに描く絵です（背景込み・角は丸めない。ゲームが角丸の枠を付けます）。
- **描き方の指定（5次のアイコン共通）:**
  - 中央に大きな記号を1つ。小さく描き込まない（ゲームでは 32〜48px で表示します）。
  - 太い輪郭線（濃い紫 #2A1430）。
  - 少ない色（3〜4色まで）。
  - 背景はほぼ単色（地の色の濃淡だけ）。地の色は**系統の色**（表の「地の色」）。
  - 人物は描かない。文字・ロゴは入れない。
- 絵柄は第1弾と同じです（見本 `style/luna_f_reference.png`）。全年齢向け。既存のゲームや実在のブランドに似せない。
- 画像が届くまでは、ゲームはコードで描いたアイコンを使います（差し替えは manifest の icons 節 `skill/<id>`）。
