この依頼書は `NEXT_REQUEST_luna.md`（9枚の依頼）の代わりです。
- あちらの「表情4枚（頭1枚まるごと）」は、この依頼書の **② 顔 f_01**（髪と顔を分けた方式）に置き換えます。
- ピンク系の5枚は、**かわいい系の着せ替え用**（①）にしました。地味な初期装備は ⓪ で別に作ります。
- 最新の素体（肩・脇修正版）は、この ZIP の `assets/sprites/rig/body_f.png` です。組み立て資料も最新版です。

肩の修正は完了済みです。今回は新しい画像を作る依頼です。

## 共通のルール（全部の絵）

**向き・絵柄・背景**
- 右向き斜め前（3/4）で描いてください。組み込み済みの素体 `rig/body_f.png` と同じ向きです。
- 絵柄は見本 `style/luna_f_reference.png` に合わせてください。ちびアニメ調、太めの濃い紫の線 `#2A1430`、セル塗り2段＋ツヤです。
- 背景は完全な透明にしてください。文字・影・枠・下絵の線は残さないでください。
- 全年齢向けです。素体はインナー着用、破れの穴の中もインナーにします。

**大きさ・位置**
- 指定の大きさ・位置で描いてください。体は 1024×1024、頭も 1024×1024、武器は 1024×512 です。
- 位置合わせはゲームがしません。**下敷きの絵に重ねてぴったり合う位置**に描いてください。
- 表情違い・色違いは、元の絵と**輪郭が1pxもずれない**ようにしてください。

**色**
- 基準色で塗ってください。ゲームが色を塗り替えます。
- 基準色は、肌 ♀ `#ffe3d3`・♂ `#f6d5be`、髪 `#b07850`、瞳 `#6a5cff` です。服の基準色は各表のとおりです。

**関節（体のパーツ）**
- 肘・膝は、各パーツの支点から72px下に描いてください。関節の前後24pxは、太さと形を急に変えないでください。
- 腕・脚は手前と奥を分けて描きます。
  - 手前の腕の枠（armF）はキャラの右腕、手前の脚の枠（legF）は右脚です。
  - 奥の枠（armB / legB）は左腕・左脚です。
- 袖・裾の上端は、素体の腕・脚と同じ丸みにしてください。肩の濃い輪郭は弱めにします。

**納品**
- ZIP で、`assets/sprites/` から下のフォルダ構成とファイル名のまま渡してください。
- 1段階ごと（①②…）に区切って納品してもらえると、順に組み込めます。

**添付**
- 毎回、見本 `style/luna_f_reference.png` を添付します。
- 体の絵は `rig/body_f.png`（♂は `rig/body_m.png` ができてからそれも）を、頭の絵は `heads/face/f_01.png` を、下敷きとして添付します。
- 位置の数値は、`rig_assembly/README.md` と `FACE_HAIR_SPEC.md` を見てください。
