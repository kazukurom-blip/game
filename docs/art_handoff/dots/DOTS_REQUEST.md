## 1. 目的：「AIっぽさ」を消して、人が描いたような絵にする

今の絵は、次の 4 つの点で「AIが描いた絵」に見えます。これを全部なくすのが今回の一番の目的です。

1. **柔らかいグラデーション**：エアブラシのような陰、ふわっとした光。
2. **細かいノイズ・質感**：布の織り目、肌のざらつき、意味のない細かい描き込み。
3. **線の太さがばらばら**：場所ごと・絵ごとに線の太さや色が違う。
4. **絵ごとに光や色の感じが違う**：同じキャラなのにパーツによって明るさ・色味が違う。

## 2. 絵柄の決まり（全部の絵に共通）

| 項目 | 決まり |
|---|---|
| 塗り | **アニメ塗り（セル塗り）**。影は **2 段**（基本の色＋影 1 段、必要なら濃い影をもう 1 段）。影の境目は**くっきり**。ぼかさない |
| ハイライト | 髪・金属・目だけに、小さく**くっきりした形**で入れる。広い光のぼかしは入れない |
| 線 | 外側の輪郭は太め、内側の線は細め。**太さは全部の絵で同じ**（型紙 1024px のとき 外 6px・内 3px 前後）。線の色は真っ黒にせず、**その部分の色を濃くした色**（例：肌の線は濃い茶、服の線はその服の色の濃い色） |
| 色の数 | **塗り分けの段の数**の決まり：1 パーツ（服 1 枚・髪 1 つ）を **基本の色＋影＋ハイライト の 3〜4 段**で塗り分ける。広いグラデーションは作らない。<br>※ **ピクセルの色を機械的に 3〜4 色へ減らす（減色）ことではありません**。線や輪郭のなめらかさ（アンチエイリアス）、段の境目の 1〜2px のなじみは残してください。減色すると輪郭がギザギザになり、質が落ちます |
| 光の向き | いつも**左上**から。影は右下にできる |
| 質感 | 描かない。布の織り目・肌のきめ・紙のざらつき・ノイズは入れない。しわは**影の形で 2〜3 本**だけ |
| 形 | 細かく描き込むより、**大きくはっきりした形**。ゲームでは小さく表示するので、遠くから見て分かる形を優先 |
| 背景 | **透明**（アイコンは除く。アイコンは §5） |
| 禁止 | 文字・ロゴ・サイン・透かし。実在のブランド・既存のゲームのキャラに似せること。全年齢向けでない表現 |

### 同じ絵柄を保つためのやり方

- **パレット（使う色の一覧）を最初に決めて固定**し、全部の絵でそこから色を選びます。P 段で作ったパレットを `pilot/palette.png` として一緒に納品してください。
- 毎回、**P 段で合格した絵**を「この絵柄で」と添付して描きます。
- 線の太さ・影の段数・光の向きを、描くたびに上の表で確かめます。

### 3-1. 決まった絵柄（2026-10-06）：**A ＋ 外側の輪郭線だけ B の太さ**

候補（`pilot/style_A.png`・`style_B.png`・`style_C.png`）から、ユーザーが **A を基本**に選びました。ゲームの大きさ（身長 約100px）に縮めて背景に置いて比べた結果（`pilot/style_compare_ingame.png`）、A は線が細くて背景に少し埋もれるので、**外側の輪郭線だけ B と同じくらい太く**します。

### 3-2. ルナ♀1人分（1 回目）の結果と、やり直しのお願い（2026-10-06）

ゲームに入れて動かし、今の絵と並べて確かめました（`pilot/round1_compare.png`）。**今回は合格にできません**。理由と、やり直しの決まりです。

**1 回目で起きたこと**
1. **描き直しになっていない**：12 枚とも、今の絵と形がほぼ同じでした（輪郭の一致 98〜99%）。今の絵に太い外枠を足して減色した**加工**で、見本 A の絵柄にはなっていません。見本 3 枚が高品質だったのは、一から全身を描いたからです。
2. **減色で質が落ちた**：影・ツヤのなじみと、輪郭のなめらかさ（アンチエイリアス 0%）が消え、ギザギザで平板になりました（§2「色の数」を直しました。減色はしないでください）。
3. **顔の線が茶色**：肌・顔の線を茶色にすると、ゲームが**髪の色**と見なして塗り替えます（ルナでは顔の輪郭がピンクになる）。
4. **瞳が基準色でない**：瞳が濃い紫で、基準色 `#6a5cff` が 0% でした。キャラ作成で瞳の色が変わりません。
5. **後ろ髪がまだ大きい**：横幅 728px。

**やり直しの決まり**
- **今の絵は「形と位置の目安」だけ**。見本 A（と §3-1 の太い外側の線）の絵柄で、**一から描いてください**。こちらの検査で、今の絵と形が 97% 以上同じなら「加工」と判定します。
- **描き方のおすすめ**：部品を 1 つずつ型紙の上で描くより、見本 A のような **1 枚の大きな絵**として描いてから部品に分ける方が、質が保てます。
  - 頭：右向き斜め前の頭（顔＋髪）を 1 枚の絵で描く → 顔・前髪・後ろ髪に分け、髪で隠れていた所（頭頂の肌・髪の内側）を描き足す。
  - 体・服：腕と脚をまっすぐ下ろした立ち姿の全身を 1 枚で描く（素体だけの絵と、服を着た絵を、**同じポーズ・同じ位置**で 2 枚）→ 型紙の枠ごとに切り分け、重なりで隠れていた関節の周りを描き足す。
- **線の色**：外側の線は濃いプラム色 `#4A1234`。**肌・顔の線は茶色にしない**（プラム色か、`#2A1430`）。髪の線は髪の基準色を濃くした茶色でよい（髪と一緒に色が変わる）。
- **瞳**は `#6a5cff` を基本に、その濃淡で塗る（瞳孔・ハイライトは別の色でよい）。
- **後ろ髪**：横幅 **560px 以内**（今の 7 割）、下端は y=760 くらいまで（肩の少し下）。毛先のカールは大きく 2〜3 個に。
- **アンチエイリアスを残す**：輪郭の外側 1〜2px は半透明でなめらかに（こちらの検査で、透明との境目のなめらかな画素が 25% 未満だとギザギザと判定します）。

**進め方（確実に質を上げるため、3 回に分けます）**
1. **頭だけ**：まず、頭の 1 枚絵（部品に分ける前）を見せてください → ユーザーが OK を出したら、顔 `f_01`＋表情 4 枚・前髪・後ろ髪に分けて納品。
2. **素体**：全身の 1 枚絵 → OK のあと素体の部品に分けて納品。
3. **初期の服 3 点と木剣**：同じく 1 枚絵 → 部品。
- 1 枚絵の段階で直しが入っても、手戻りは小さく済みます。

## 4. 大きさ・形式の決まり（軽くするため）

- **型紙のある絵（素体・顔・髪・服・武器）は、今と同じ型紙どおりの大きさで描く（体・顔・髪・服は 1024×1024、武器は 1024×512）**。型紙・枠・支点は変えません（ゲームの体の組み立てが型紙の位置で決まっているため）。
  - **体型の基準は `ref/current_rig/` の今の絵**です（♂の体つきの描き直し・肩口の修正を入れた最新の物）。型紙 `rig/templates/` は枠と支点の位置を示す下絵で、体型の細かい形は今の絵に合わせてください。
  - 型紙と書き方：[`../HERO_PARTS_GUIDE.md`](../HERO_PARTS_GUIDE.md)（素体・服・武器）、[`../FACE_HAIR_SPEC.md`](../FACE_HAIR_SPEC.md)（顔・表情・髪）。**絵柄の指定だけはこの文書が優先**です（前の指示書の「画風」の行は無視してください）。
- **アイコンは 256×256**。
- **PNG で納品**。透明の背景（アイコン以外）。
- **武器だけは 1024×512（横長）**。型紙 `rig/layout_weapon.png` と下絵 `rig/templates/weapon/` の大きさのとおりです（持ち手の支点は (240, 256)）。
- 軽くする作業（ゲーム用にさらに縮める・WebP にする・使うときだけ読み込む）は、**こちら側で自動で行います**。Dots の側では、指定より小さく縮めたり、JPEG など画質の落ちる形式にしたりしないでください。
- **生成したあとの仕上げ加工は OK です**（むしろお願いします）。
  - 指定の大きさへのサイズ調整（大きく生成して、指定の大きさに縮める。縮めるときは高品質な方法で。ぼやけた拡大はしない）
  - 枠・支点への位置合わせ（型紙の十字・枠に合わせて動かす・回す）
  - 透明部分の整理（背景・ゴミ・半透明のにじみを消す。輪郭の外側 1〜2px のなめらかさ（アンチエイリアス）は残してよい）
  - 色数の整理（パレット・基準色にそろえる。基準色はぴったりその値に）
  - ただし、型紙の枠からはみ出さないこと、線の太さ（外 8〜10px・内 2〜3px）が仕上げのあとでも保たれていることを確かめてください。
- **色替えのある絵は「基準色」で塗る**：服・髪・肌は、ゲームがプレイヤーの選んだ色に塗り替えます。各行の指示書の「基準色」で塗り、影とハイライトも基準色の濃淡で付けてください（別の色相を混ぜると塗り替えが崩れます）。
- **D 段（ネタ装備）は色替えしません**。そのアイテムの見た目の色で、自由に描いてください。

## 7. 納品のしかた

- `assets/sprites/` の下と同じフォルダの形で、ZIP にまとめて納品（例：`rig/top/tshirt_f.png`、`icons/skill/hn_glitch_cat.png`）。
- 1 回の ZIP は **段ごと**（P、A、B の一部…）。B は量が多いので、素体と顔 → 髪 → 服 → 武器の順に分けて構いません。
- **自分で確かめてから納品**：
  - ファイル名と大きさが一覧のとおり
  - 型紙の枠からはみ出していない・支点の位置がずれていない
  - 背景が透明（アイコン以外）
  - 文字・ロゴ・透かしが無い
  - §2 の決まり（影 2 段・くっきり・線の太さ・左上の光・質感なし）を守っている
- こちらでは、届いた ZIP を自動の検査（`tools/check_art.mjs`）にかけ、ゲームの画面で並べたスクショで確かめます。
