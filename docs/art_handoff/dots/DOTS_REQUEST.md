## 1. 目的：「AIっぽさ」を消して、人が描いたような絵にする

今の絵は、次の 4 つの点で「AIが描いた絵」に見えます。これを全部なくすのが今回の一番の目的です。

1. **柔らかいグラデーション**：エアブラシのような陰、ふわっとした光。
2. **細かいノイズ・質感**：布の織り目、肌のざらつき、意味のない細かい描き込み。
3. **線の太さがばらばら**：場所ごと・絵ごとに線の太さや色が違う。
4. **絵ごとに光や色の感じが違う**：同じキャラなのにパーツによって明るさ・色味が違う。

## 2. 絵柄の決まり（全部の絵に共通）

| 項目 | 決まり |
|---|---|
| 塗り | **アニメ塗り（セル塗り）**。影は **2 段**（基本の色＋影 1 段、必要なら濃い影をもう 1 段）。影の境目は**くっきり**。ぼかさない |
| ハイライト | 髪・金属・目だけに、小さく**くっきりした形**で入れる。広い光のぼかしは入れない |
| 線 | 外側の輪郭は太め、内側の線は細め。**太さは全部の絵で同じ**（型紙 1024px のとき 外 6px・内 3px 前後）。線の色は真っ黒にせず、**その部分の色を濃くした色**（例：肌の線は濃い茶、服の線はその服の色の濃い色） |
| 色の数 | 1 パーツ（服 1 枚・髪 1 つ）あたり **基本の色＋影＋ハイライト の 3〜4 色まで**。グラデーションの中間色は作らない |
| 光の向き | いつも**左上**から。影は右下にできる |
| 質感 | 描かない。布の織り目・肌のきめ・紙のざらつき・ノイズは入れない。しわは**影の形で 2〜3 本**だけ |
| 形 | 細かく描き込むより、**大きくはっきりした形**。ゲームでは小さく表示するので、遠くから見て分かる形を優先 |
| 背景 | **透明**（アイコンは除く。アイコンは §5） |
| 禁止 | 文字・ロゴ・サイン・透かし。実在のブランド・既存のゲームのキャラに似せること。全年齢向けでない表現 |

### 同じ絵柄を保つためのやり方

- **パレット（使う色の一覧）を最初に決めて固定**し、全部の絵でそこから色を選びます。P 段で作ったパレットを `pilot/palette.png` として一緒に納品してください。
- 毎回、**P 段で合格した絵**を「この絵柄で」と添付して描きます。
- 線の太さ・影の段数・光の向きを、描くたびに上の表で確かめます。

## 3. P 段：見本（最初にこれだけ）

1. **絵柄の候補を 3 つ**：ルナ♀（ピンクのツインテールの女の子・初期の服）の全身を、同じポーズ・同じ服で 3 枚。変えるのは**塗りと線だけ**です。
   - 3 つとも **§2 の決まり（限られた色のセル塗り・グラデーションと質感なし）の中で**変えます。
   - 例：A＝細めの線・すっきりしたアニメ塗り ／ B＝太めの線・色の差が大きいポップな塗り ／ C＝線の色をその部分の色に寄せた、やわらかい印象のセル塗り（影の境目はくっきり・色むらは入れない）
   - 参考：今の絵 `ref/current_luna.png` と `ref/current_rig/`（形と服の基準。絵柄はまねしない）
   - 保存先：`pilot/style_A.png` / `style_B.png` / `style_C.png`（1024×1024）
2. ユーザーが 1 つ選ぶ（または直しを伝える）。
3. **選ばれた絵柄でルナ♀を1人分**作る。
   - 素体 `rig/body_f.png`
   - 顔 `heads/face/f_01.png` と表情 4 枚（`_blink` `_hurt` `_shout` `_happy`）
   - 髪 `heads/hair/f_twin.png` と後ろ髪 `f_twin_back.png`
   - 初期の服 `rig/top/plainShirt_f.png`・`rig/bottom/plainPants_f.png`・`rig/shoes/oldShoes_f.png`、武器 `rig/weapon/woodSword.png`
   - これをゲームに入れて、動かしたときに破綻しないかをこちらで確かめます。合格したら B 段の残りへ進みます。

## 4. 大きさ・形式の決まり（軽くするため）

- **型紙のある絵（素体・顔・髪・服・武器）は、今と同じ 1024×1024 の型紙どおりに描く**。型紙・枠・支点は変えません（ゲームの体の組み立てが型紙の位置で決まっているため）。
  - **体型の基準は `ref/current_rig/` の今の絵**です（♂の体つきの描き直し・肩口の修正を入れた最新の物）。型紙 `rig/templates/` は枠と支点の位置を示す下絵で、体型の細かい形は今の絵に合わせてください。
  - 型紙と書き方：[`../HERO_PARTS_GUIDE.md`](../HERO_PARTS_GUIDE.md)（素体・服・武器）、[`../FACE_HAIR_SPEC.md`](../FACE_HAIR_SPEC.md)（顔・表情・髪）。**絵柄の指定だけはこの文書が優先**です（前の指示書の「画風」の行は無視してください）。
- **アイコンは 256×256**。
- **PNG で納品**。透明の背景（アイコン以外）。
- 軽くする作業（縮める・WebP にする・使うときだけ読み込む）は、**こちら側で自動で行います**。Dots の側で縮めたり画質を落としたりしないでください。
- **色替えのある絵は「基準色」で塗る**：服・髪・肌は、ゲームがプレイヤーの選んだ色に塗り替えます。各行の指示書の「基準色」で塗り、影とハイライトも基準色の濃淡で付けてください（別の色相を混ぜると塗り替えが崩れます）。
- **D 段（ネタ装備）は色替えしません**。そのアイテムの見た目の色で、自由に描いてください。

## 5. A 段：スキルアイコン 40 枚

一覧の A 段の「注意」の列に、中央に描く記号と地の色が書いてあります。

- 256×256 の正方形いっぱいに描く（背景込み。角は丸めない。ゲームが枠を付ける）。
- **中央に大きな記号を 1 つ**。ゲームでは 32〜48px で表示するので、小さく描き込まない。
- 太い輪郭線（濃い紫 #2A1430）。色は 3〜4 色まで。背景は地の色の濃淡だけ。
- 人物は描かない。文字なし。
- 今あるスキルアイコン 84 枚と並べて違和感がないように（見本：`ref/current_skill_icons.png`）。
- 塗りは §2 の決まりに合わせる（グラデーション・質感を入れない）。

## 6. D 段：ネタ装備（見た目だけの装備）32 種

クエストでもらえる「能力はほぼ 0、見た目で笑わせる」装備です。名前と説明文は一覧の「内容」の列にあります。

- 着た形は、**元にした服と同じ枠**に描きます（例：「バナナのヘルメット」は helmet の枠、「冷凍マグロ」は bat の武器の型紙。持つ位置も bat と同じ）。
- ♀と♂の両方を描きます（武器は 1 枚で両方に使います）。
- 形は名前のとおりに、はっきり描く（マグロはマグロ、ネギはネギ、段ボールの鎧は段ボール）。
- アイコン `icons/equip/<アイテムID>.png` も 1 枚ずつ描きます。

## 7. 納品のしかた

- `assets/sprites/` の下と同じフォルダの形で、ZIP にまとめて納品（例：`rig/top/tshirt_f.png`、`icons/skill/hn_glitch_cat.png`）。
- 1 回の ZIP は **段ごと**（P、A、B の一部…）。B は量が多いので、素体と顔 → 髪 → 服 → 武器の順に分けて構いません。
- **自分で確かめてから納品**：
  - ファイル名と大きさが一覧のとおり
  - 型紙の枠からはみ出していない・支点の位置がずれていない
  - 背景が透明（アイコン以外）
  - 文字・ロゴ・透かしが無い
  - §2 の決まり（影 2 段・くっきり・線の太さ・左上の光・質感なし）を守っている
- こちらでは、届いた ZIP を自動の検査（`tools/check_art.mjs`）にかけ、ゲームの画面で並べたスクショで確かめます。
