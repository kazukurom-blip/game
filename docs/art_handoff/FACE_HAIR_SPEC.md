# 顔・髪の分割方式（キャラ作成で顔10種類・髪型・髪の色・肌の色を選ぶ）

主人公の頭を、次の **3枚の絵の重ね合わせ**で作ります。

1. 後ろ髪（体の後ろ）
2. 顔
3. 前髪

顔は全クラス共通で、♀♂別にそれぞれ10種類あります。髪型は顔と自由に組み合わせられます。髪の色と肌の色は、ゲームが絵を自動で塗り替えます。

## 1. 配置図（3枚とも共通）

今の頭の配置図と同じです。
- 大きさ: **1024×1024**、透明背景
- 単位: **1単位 = 10px**
- 支点（頭の中心）: **(512, 400)**
- 頭頂の線: y=220
- 目の高さ: y≈450
- 顎: y=560
- 向き: 右向き斜め前（3/4）。体（`rig/body_f.png`）と同じ向きです。

**3枚を重ねたとき、ぴったり1つの頭になること**が条件です。どの顔にどの髪型を重ねても合うように、次のように描きます。

- **頭の形（頭蓋の輪郭・耳の位置・顎の位置・目の高さ）は、全部の顔で同じ**にします。
  - ♀は顔1番 `face/f_01.png` を、♂は顔1番 `face/m_01.png` を下敷きにして、輪郭線をなぞります。
  - 顔ごとに変えるのは、目・眉・口・頬・まつ毛・顎のごく小さな丸みだけです。
- 前髪は、その共通の頭の形にかぶせて描きます。頭頂の丸みを髪で覆い、額の上・こめかみ・耳の上の生え際まで描きます。

## 2. 3枚それぞれに描くもの

| 絵 | 保存先（`assets/sprites/` の下） | 描くもの | 描かないもの |
|---|---|---|---|
| 顔 | `heads/face/<性別>_<番号>.png`（例 `f_01`） | 肌色の頭全体（髪で隠れる頭頂も肌で塗る）・耳・目・眉・鼻・口・頬の赤み | 髪（1本も描かない）・首・帽子・ネコミミ |
| 顔の表情 | `heads/face/<性別>_<番号>_blink.png` / `_hurt` / `_shout` / `_happy` | 顔の絵と同じで、目・眉・口・頬だけを変える | 同上。輪郭は1pxも動かさない |
| 前髪 | `heads/hair/<性別>_<髪型>.png`（例 `f_twin`） | 前髪・頭頂の髪・もみあげ・耳の上の髪（顔の前と頭の上に重なる部分） | 顔・後ろに垂れる髪・ツインテール・ポニーテールの房 |
| 後ろ髪 | `heads/hair/<性別>_<髪型>_back.png` | 後頭部の髪・ツインテール・ポニーテール・長い後ろ髪（体の後ろに表示） | 顔・前髪 |

## 3. 色（自動で塗り替える）

色替えが合うように、**基準色で塗ります**。陰や光は、基準色の濃淡で付けてください。

| 対象 | 基準色 |
|---|---|
| 肌 ♀ | `#ffe3d3` |
| 肌 ♂ | `#f6d5be` |
| 髪（全部の髪型） | 明るい茶色 `#b07850` |
| 瞳 | 青紫 `#6a5cff` |
| 線 | 濃い紫 `#2A1430`（塗り替えない） |

ゲームはこの基準色を、キャラ作成で選んだ色に塗り替えます。
- 髪の色: 14色
- 肌の色: 8色
- 瞳の色: 10色

## 5. manifest（ゲーム側。描く人は書かなくてよい）

```json
"faces": { "f_01": { "file": "heads/face/f_01.png", "expr": { "blink": "heads/face/f_01_blink.png", "hurt": "...", "shout": "...", "happy": "..." } } },
"hairs": { "f_twin": { "file": "heads/hair/f_twin.png", "back": "heads/hair/f_twin_back.png", "base": "#b07850" } },
"faceBase": { "skin": { "f": "#ffe3d3", "m": "#f6d5be" }, "eye": "#6a5cff" }
```

- look に `face`（例 `f_01`）を持たせます。髪型は今の `hair`、色は `hairColor` / `skin` / `eyeColor` を使います。
- 顔の絵がある時は、`顔 + hair の前髪 + 後ろ髪` で描きます。
- 無い時は、今の `heads.<クラス>_<性別>`（1枚の頭）か、コードの頭で描きます。
