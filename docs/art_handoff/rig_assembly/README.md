## 1. 単位と座標

- **1単位**: ゲーム内で等倍（scale 1）のとき画面の 1px。主人公の背丈は **84単位**（頭頂〜足裏、アホ毛は除く）。
  - ゲーム画面は 1280×720 なので、主人公は画面上で約 84px です。
- **体の配置図**: 1024×1024、**1単位 = 8px**。読み込み後は 1単位 = 4px で保持します。
- **頭の配置図**: 1024×1024、**1単位 = 10px**。
- **向き**: 絵は**右向き**で描きます。左向きはゲームが左右反転します。
- **y は下が正**です。下の表の値は、上が負になります。

## 3. 倍率・回転（毎フレーム）

**全体:**
- 足元（足裏の中心）を原点に scale 倍します。ゲーム内は scale 1、カットインなどでは大きく描きます。
- 左向きのときは x を反転します。

**上半身**（胴・腕・頭）:
- `translate(hx, 股の高さ + bob)` のあと `rotate(tilt)` します。
- tilt は + が前傾です。
- bob は上下の弾み、hx は重心の左右移動です。

**腕:**
- 肩を中心に角度 **a** で回します。0 = 真下、+ = 前（顔の向き）。
- 肘で **e** だけ曲げます。+ = 前腕が前へ。

**脚:**
- 股関節を中心に角度 **a** で回します。+ = 前へ振り出す。
- 膝で **k** だけ曲げます。すねが後ろへ折れる向きです。

**足:**
- 足首を中心に `−(a − k) × 0.85` 回します。脚が傾いても、足はほぼ地面と平行に保ちます。

**頭（画像の頭）:**
- **首の付け根**を中心に回します。
  - 角度 = 頭の傾き×1.6 ＋ 上半身の傾き×0.55 ＋ 状態ごとの振り。
  - 状態ごとの振り: 歩きのうなずき ±0.05、攻撃の踏み込み、被弾 −0.12、ジャンプ −0.07。
  - 全体の範囲は ±0.4 です。
- ひねりに合わせて頭を横に最大 9% 縮めます（振り向いたように見せるため）。
- 後ろ髪は頭と一緒に動きます。そのうえで、結び目 (0, −6) を中心に髪だけ揺れます。

**今のルナ v4 の調整値**（`assets/sprites/manifest.json`）:
- `rig.profile.f.sx = 9.4`
- 胴を横に ×1.12
- 靴を ×0.85
- 後ろ髪を ×0.86・上へ 1

## 4. 肘・膝の曲げ方

腕・脚の1枚の絵を次のように曲げます。
1. 支点から **9単位**（関節）の前後 **±3単位**を、0.75単位の細い帯に分けます。
2. 帯ごとに角度を少しずつ変えて並べます。上の骨の角度 → 下の骨の角度へ、なめらかにつなぎます。
3. 帯は前後の境目で切り抜き、0.14単位ずつ重ねます。折れ目・隙間・ギザギザを出さないためです。

このため、絵に必要なのは次のとおりです。
- 関節の前後 3単位（24px）が**まっすぐで、太さが急に変わらない**こと。
- 関節が**ちょうど 9単位の位置**にあること。

## 5. 重ね順（前向き。奥 → 手前）

1. 背中の物（翼・スカーフ）、後ろ髪、服の背中側
2. 後ろの腕
3. 後ろの脚 → 後ろの足 → 前の脚 → 前の足
4. 胴
5. 頭（前の頭 → 帽子・メガネ・汗）
6. 前の腕 → 武器 → 前の手（武器を握って見えるように、手だけもう一度描く）

## 6. 歩き方・立ち方（`makePose`）

### 歩き

1周 **0.6秒**で2歩です。ゲーム内は1周を 10コマで描きます。動画はコマを間引かずに描いています。

`s = sin(2πt/0.6)`、`c = cos(2πt/0.6)` として、各部を次のように動かします。

**脚:**
- 前の脚の角度 = 0.44·s、後ろの脚の角度 = −0.44·s（♂は 0.5）
- 膝の曲げ = 脚を前へ振り出している間（遊脚）だけ大きく曲げます。式は `max(0, ±c)^1.3 × 0.95 + 着地の衝撃 0.12 + 0.06` です。

**腕:**
- 角度 = ∓0.45·s（脚と逆に振る）
- 肘の曲げ = 0.3 ＋ 後ろへ振る間 0.25

**上半身:**
- 弾み bob = −|c|·1.8 ＋ 0.9（脚がそろう瞬間がいちばん高い）
- 前傾 tilt = 0.07
- 腰のひねり = −0.9·s

### 立ち（待機）

4.8秒の周期で次の動きをします。
- 呼吸 bob ±0.75
- 重心の左右 hx ±0.45
- 頭の小さな揺れ

## 7. 新しい体の案との照合（`joint_compare.png`）

案を半分に縮め（1単位 ≈ 14.8px）、足裏と頭頂を骨格に合わせて重ねました。目で読んだおおよその値です。

| 場所 | 案 | 骨格 | 判定 |
|---|---|---|---|
| 股 | 約 26 | 24 | ほぼ合う |
| 膝 | 約 15.5 | 15 | 合う |
| 足首 | 約 6〜7 | 6 | 合う |
| 顎 | 約 53 | 50 | 頭がやや小さく高い |
| 肩の付け根 | 高さ約 48、左右 約 ±7.5 | 46、既定 ±7.2 | ほぼ合う |

**結論:**
- 案の頭身は骨格 v2 にほぼ合っています。**支点を無視する必要はありません**。
- 案を配置図の枠に分けて描き直せば、`fit:false` で使えます。分け方: 胴／腕2本をまっすぐ下／脚2本をまっすぐ下／足2つ。
- 支点を無視すると、回したときに関節が外れます。ゲームは各パーツを支点の周りで回すからです。

**直してほしい点:**
1. **脚と足を右向き寄り（3/4）に**してください。つま先を右へ向けます。今の案は正面向きなので、横へ歩くと「正面のまま横歩き」に見えます。
2. 腕・脚は**関節がちょうど 9単位（72px）**の位置にくるように描いてください。関節の前後 3単位はまっすぐにします。
3. 腕の上端は肩の丸み、脚の上端は股関節の上 5単位まで描いてください（胴の下に隠れる「のりしろ」）。関節で回しても隙間が出なくなります。
4. 顎を 3単位ほど下げてください（顎 50・頭の中心 66）。首の付け根（48）が胴の首の上端に重なるようにします。
5. 基準色に合わせてください: 肌 #ffe3d3、インナー #3a3346、スパッツ #2a2633、靴 #5b5266。
