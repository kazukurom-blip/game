# 次に作ってほしい画像（ルナを仕上げる 9枚）

前提:
- 体は、組み込み済みの右向き3/4の素体 `assets/sprites/rig/body_f.png`（肩・脇修正版）を基準にします。
- 頭は承認済みの `heads/luna_f.png` / `heads/luna_f_back.png` のままです。
- 毎回添付するもの: 見本 `style/luna_f_reference.png`、素体 `rig/body_f.png`、組み立て資料 `rig_assembly.zip` の README。

## A. 表情 4枚（頭）

いちばん効果が大きい4枚です。顔が固定されて見える問題がなくなります。

| 保存先 | 表情 | 使う場面 |
|---|---|---|
| `assets/sprites/heads/luna_f_blink.png` | 目を閉じた（まばたき） | 待機中に時々 |
| `assets/sprites/heads/luna_f_hurt.png` | 痛がる「> <」の目、口をくっと結ぶ | 被弾 |
| `assets/sprites/heads/luna_f_shout.png` | 口を大きく開けた叫び、強い目 | 攻撃・スキル |
| `assets/sprites/heads/luna_f_happy.png` | 「^ ^」の笑顔 | レベルアップ・勝利 |

**条件:**
- `heads/luna_f.png` を下敷きにして、**同じ 1024×1024・同じ位置・同じ大きさ・同じ髪**で描いてください。変えるのは目・眉・口・頬だけです。
- 重ねて比べたとき、輪郭と髪が1pxもずれないのが理想です。ゲームは表情を差し替えるだけなので、ずれると切り替えた瞬間に頭が跳ねます。
- 後ろ髪・ネコミミ・帽子は描かないでください。背景は透明です。

## B. 初期装備 5枚（体のパーツ）

今のゲームの初期装備です。今はコードの仮の絵で描いています。

| 保存先 | 内容 | 描く枠 | 基準色（主 / アクセント） |
|---|---|---|---|
| `assets/sprites/rig/top/hoodie_f.png` | ピンクのパーカー | 背中・胴・奥の腕・手前の腕 | `#ff6fb5` / `#ffffff` |
| `assets/sprites/rig/bottom/skirt_f.png` | プリーツスカート | 胴・奥の脚・手前の脚 | `#ff8ac8` / `#ffffff` |
| `assets/sprites/rig/shoes/sneakers_f.png` | スニーカー | 奥の足・手前の足 | `#f4f4f4` / `#ff6fb5` |
| `assets/sprites/rig/hat/catEars_f.png` | ネコミミのカチューシャ | 頭の物 | `#ff8ac8` / `#ffe0f0` |
| `assets/sprites/rig/weapon/knife.png` | ポケットナイフ | 武器（別の配置図） | `#c9ccd6` / `#ff6fb5` |

**体のパーツ（パーカー・スカート・スニーカー）の条件:**
- **`rig/body_f.png` を下敷き**にし、素体の上に着せた形で、**同じ枠・同じ位置**に描いてください。1024×1024、透明背景です。
  - 古い下絵（templates）は正面向きなので、向きの参考にはしないでください。
- 向きは右向き3/4です。
  - **手前の腕の枠（armF）= キャラの右腕**で、胴の前に重なります。
  - 奥の腕の枠（armB）= 左腕で、胴の後ろに隠れます。脚も同じで、手前の脚の枠（legF）が右脚です。
- 袖・裾の関節のルール:
  - 腕・脚の袖は、**肘・膝が支点から72px下**です。関節の前後24pxは形と太さを急に変えないでください。
  - 袖の上端は素体の腕と同じ丸みにし、胴の肩の丸みに重なる形にします。
  - 肩の濃い輪郭は弱めにしてください（継ぎ目が目立たないように）。
- 色:
  - 基準色ぴったりで塗ってください。色違いはゲームが自動で作ります。
  - 線は濃い紫 `#2A1430` です。
- 素体の肌・インナー・顔は描かないでください。服の部分だけを描きます。

**頭の物（ネコミミ）の条件:**
- 体の配置図 `rig/layout_f.png` の左上の「頭の物」の枠（16,16・512×432）に描いてください。
  - 支点 (272,288) = 頭の中心、1単位 = 8px です。
  - 頭頂は y=144（−18単位）、顎は y=416（+16単位）です。
- `heads/luna_f.png` を 0.8 倍に縮めて頭の中心を (272,288) に合わせると、頭とぴったり重なります。それを下敷きにして、頭頂の少し後ろにカチューシャを乗せる位置で描いてください（下敷きの頭は消してから納品）。

**武器（ナイフ）の条件:**
- 1024×512 に、右向きで水平に描いてください。
- 握る所を (240,256) に置き、**握る所の真ん中にマゼンタ（#FF00FF）の小さな丸**を描いてください。
- 手は描かないでください。
