## 1. どんなゲームか（遊びの柱）

1. **狩り** — 自分の Lv に合った狩り場を見つけ、足場と縄の上で敵を倒し続ける気持ちよさ。敵ごとに動き・攻撃・弱点が違い、マップの形（段差・縄・はしご）で狩り方が変わる。「この狩り場はおいしい」を自分で見つけるのが楽しみ。
2. **育成** — Lv が上がるたびに AP 5・SP 3 を **自分の手で**振る。振り方で強さが変わり、取り返しがつきにくい緊張感（振り直しはまれな品）。経験値の表はクラシックの形のまま、1 人用の補正で現実的な時間（Lv70 まで約 50 時間、Lv120 まで約 135 時間）。
3. **装備と書** — 店の装備、敵が落とす装備（当たり外れ・上質）、そして **10%・60%・100%・呪い付き 30%/70% の書** で強化するドキドキ。壊れる危険と回数の制限がクラシックらしさの核。
4. **転職** — Lv10（魔法使い 8）・30・70・120 の 4 回。職ごとの試験（試しの珠、もう一人の自分、賢者の石のクイズ、紅と蒼の印）。転職のたびに遊び方が大きく変わる。
5. **1 人用ダンジョン（PQ 相当）** — 段階ごとの仕掛け（縄の組み合わせ・迷路・卵運び）を 1 人で解く。毎日 5 回まで。メダルで装備と交換。
6. **ボス** — 地域のボス（6〜12 分）と大ボス 3 体（30〜40 分、段階・部位・制限時間）。最後は「星を呑む者」。

## 2. 1 人用で MMO らしさを出す工夫

| MMO の要素 | 本作での形 |
|---|---|
| 町のにぎわい | 町に NPC を多めに置く（各町 8〜12 人）。名前と役割があり、クエストでつながる。町の中を歩く「通りすがりの冒険者 NPC」（見た目と職がランダム、座ったり歩いたり、たまに吹き出しで一言） |
| 自由市場 | **にぎわい市場**（全部の町から入れる共通の場所）。露店の NPC 冒険者が日替わりで中古の装備・書・素材を売る。書で強化済みの「掘り出し物」もある。相場が少し動く |

## 3. 画面と操作

- **キーボード中心**（マウスはウィンドウの操作だけ）。矢印で移動、Alt ジャンプ、Ctrl 攻撃、Z 拾う、Space 話す、スキル・薬はクイックスロット（Shift/Ins/Home/PgUp/Del/End/PgDn/A と 1〜8 の 16 キー）。ノートパソコン用の配置も用意。詳しくは UI.md。
- **ジャンプ・縄・はしご**: 縄・はしごは ↑ でつかまる、つかまっている間は攻撃できない、左右＋ジャンプで飛び降りる。浮いた足場は下から乗れて ↓＋ジャンプで降りる。伏せ（↓）で低い攻撃をよける・伏せ突き。
- **物理の手ざわり**（クラシックに近づける目安）: 歩く速さ 125 px/秒（速さ 100）、ジャンプの高さ 約 75 px（ジャンプ 100）、重力 2000 px/秒²、空中では向きは変えられるが勢いはほとんど変わらない、縄の上り下り 90 px/秒。
- **画面**: 800×600 の基準（5 章）。ステータスバーは下、ミニマップは左上。

## 5. 絵の方向（すべてドット絵）

**決まったこと（ユーザー）: 敵・NPC・主人公はすべてドット絵。** 背景・UI・アイコン・エフェクトもドット絵でそろえる。

### 5-1. 解像度の基準

| 項目 | 値 | 理由 |
|---|---|---|
| ゲームの内部解像度 | **800×600**（4:3） | クラシックの見え方。画面に入る広さ（横 800 px）が狩りの手ざわりを決める |
| 表示 | 内部の 800×600 を**整数倍**（×1 / ×2 / ×3）で拡大。画面に合わない時は黒い帯（レターボックス）。拡大は「最近傍」（`imageSmoothingEnabled = false`、CSS は `image-rendering: pixelated`） | ドットがにじまない |
| 横長の画面（任意） | 設定で 1066×600（16:9）も選べる案。狩り場が少し広く見える。最初は 800×600 だけ作る | 将来の選択肢 |
| ドットの大きさ | **1 ドット = 内部の 1 px**（絵を 2 倍に描いて縮める、はしない） | 線の太さがそろう |
| タイル（地形） | **16 px** の格子。地面・足場は 16×16 の部品を並べる。足場の厚さ 16、地面の表面の飾り 16〜32 | 組み立てやすい |
| 縄・はしご | 幅 8（縄）・16（はしご）、16 px ごとの繰り返し | |
| 主人公の高さ | 立ち絵で **約 52 px**（帽子なし。頭身 約 2.5）。1 コマの枠は **64×80**（武器・マントがはみ出す分の余白込み）。足元の中央が基準点 | 800×600 の画面で、横に約 15 人分。クラシックの見え方に近い |
| NPC | 人の NPC は主人公と同じ大きさ・同じ部品の仕組み（着せ替えで作る）。特別な NPC（大きな人・動物）は 96×96 まで | |
| 敵 | 小 **24〜32 px**（貝・スライム・小鳥）、中 **40〜64 px**（キノコ・イノシシ・人型）、大 **72〜112 px**（ゴーレム・ドレイク・竜の番兵）、ボス **128〜256 px**、大ボスは部位に分けて **最大 400×320**（焔の巨像の腕など） | 下の 5-3 |

| アイコン | 32×32（アイテム・スキル）。スキルは 32×32 と、使えない時の灰色版 | |
| UI の字 | ドット絵の字（日本語は 12 px と 16 px の 2 種。英数字 8×12 の小さい字）。字の作り方は PLAN.md M1 | |

### 5-2. 主人公の着せ替え（部品を重ねる）

- 部品（下から順に重ねる）: **マントの後ろ → 後ろ髪 → 体（肌） → 下衣 → 靴 → 上着（全身） → 腕（肌） → 手袋 → 顔（目・口） → 前髪 → 帽子 → 盾 → 武器（後ろ/前の 2 枚）→ マントの前**。
- 各部品は「型紙」（体の各コマの首・へそ・手・額の位置の印）に合わせて描く。部品の絵に「基準点」を持たせ、コマごとに型紙の印へ貼る（クラシックの方式と同じ考え方。今の NEON VICE STORY の `src/render/rig.js` の仕組みを参考にできる）。
- 向きは**右向きだけ描き、左は反転**。
- 髪・肌・服の色違いは「色の置き換え（パレットの差し替え）」で作る（髪の色 8 色を 1 枚から）。
- 帽子をかぶった時の髪: 帽子ごとに「髪を隠す量」（全部・前髪だけ残す・隠さない）を持たせる。

**動きとコマ数**（1 部品あたり。体・上着・下衣・靴・手袋・腕は全部の動きを描く。帽子・髪・顔は頭の位置がずれるだけなので、頭の角度が変わるコマ（倒れ・伏せ・はしご）だけ別の絵）

### 5-4. 色・線・影の決まり

- **全体のパレット**: ゲーム全体で 1 つの「基準パレット」を決める（**64 色**。肌 4 段・髪の基本 8 色 × 3 段・空と海の青・草の緑・岩の茶・金・闇の紫 など）。どの絵もこの 64 色から選ぶ（地域ごとに 8 色まで追加してよい）。
- **1 枚の色数**: キャラの部品 1 つ **16 色以内**、敵 **24 色以内**、ボス **32 色以内**、背景の 1 層 **32 色以内**。
- **線**: 1 ドットの外側の線。真っ黒でなく「その部分の一番暗い色」（髪の線は髪の暗い色）。光の当たる上側の線は 1 段明るくしてよい。
- **影**: 光は**左上**から。塗りは 3 段（明るい・ふつう・暗い）、多くても 4 段。キャラと敵に網かけ（ディザ）は使わない。背景の遠い層だけ少し使ってよい。
- **半透明は使わない**（絵の透明は「完全に透明」か「完全に不透明」だけ）。半透明が要るもの（影・光・魔法）はエフェクトの層で、プログラムで重ねる。
- **足元の影**: キャラと敵の足元に、プログラムで小さな楕円の影（半透明の黒）。

### 5-6. エフェクトの描き方

- スキルのエフェクトはドット絵のコマ送り（4〜10 コマ、1 コマ 0.05〜0.08 秒）。大きさは 64〜256 px。
- 光る物（魔法・光・炎）は**加算で重ねてよい**（プログラムで `globalCompositeOperation = 'lighter'`）。絵そのものは不透明なドット。
- 当たった時の火花（4 コマ）、Lv アップ（光の柱 12 コマ）、ポータル（光の渦 8 コマのループ）、書の成功/失敗、転職は共通の絵。
- ダメージの数字はドット絵の数字の絵（UI.md 1-3）。

### 5-7. ドット絵を誰がどう作るか

**作り方の基本**: 「画像生成 AI で下絵 → 道具で後処理（縮小・減色・線の掃除）→ 人の目で直す」。手直しは無料のドット絵の道具（Aseprite・LibreSprite・Piskel のどれか）で行う。担当はアート担当（AI での生成と後処理）とユーザー（合否の判断）。

**AI への依頼の形**（1 枚ずつ。文は英語でも日本語でもよいが、毎回同じ書式にする）:

```
[種類] 横スクロールのゲームの敵のドット絵（右向き・真横から）
[大きさ] 最終 48×48 ドット。下絵は 1 ドットを 8×8 のマスにして 384×384 で描く
[中身] だいだい色のかさの小さなキノコの魔物。丸い目、短い足。かわいい。
[決まり] 1 ドットの外側の線（黒でなく暗い色）、光は左上、塗りは 3 段、網かけ無し、
        色は 16 色以内、背景は単色の緑（#00FF00）、ぼかし・グラデーション・文字・影の床は無し
[コマ] 1 枚に横並びで 4 コマ（立ち 2・歩き 2）。コマの間は 8 マス空ける
[参考] 基準パレットの画像・同じ地域の敵の見本 1 枚を添付
```

- **大きさの決まり**: 下絵は「最終のドット数 × 8」（または ×4）で描かせ、1 ドット = 8×8 のマスにそろえさせる。最終の大きさは 5-1・5-3 の区分から選ぶ。
- **1 回で全部のコマを作らせない**: まず「立ち」の 1 コマを決め、合格したらそれを添付して残りのコマ（同じ大きさ・同じ色）を作らせる。着せ替えの部品は、型紙（体の各コマ）の画像を添付して、その上に服を描かせる。
- **後処理**（`classic/tools/pixel_fix.mjs` を M1 で作る）:
  1. 背景の単色（#00FF00）を透明にする。
  2. マスの大きさ（8 など）を見つけて、**最近傍で 1/8 に縮小**（各マスの一番多い色を取る）。
  3. **減色**: 基準パレットの近い色に置き換え（色数の上限を超えたら、使う数の少ない色から近い色へまとめる）。
  4. **半透明をなくす**（アルファ 128 以上は不透明、それ未満は透明）。
  5. ぽつんと 1 ドットだけの色（ノイズ）を周りの色にする。外側の線が切れている所を印で知らせる（自動では直さない）。
  6. 枠の大きさ（64×80 など）に、足元の中央を基準点として置く。
  7. 検査: 色数・大きさ・基準点・コマ数を `classic/tools/check_pixel.mjs` で確かめる（今の `tools/check_art.mjs` の考え方を流用）。
- **人の目で直す所**: 顔（目の位置がコマでずれていないか）、手と武器の位置、線の切れ、色の段の数。
- 合否はユーザーが「見本の画面」（`classic/tests/art_preview.html`、ゲームの背景の上で動かして見られる頁）で決める。
- **AI が苦手な物は手で描く**: 文字・UI の枠・タイル（つなぎ目）・小さなアイコン（32×32 は手で描いた方が早い）・数字。
- 権利: AI に「◯◯のゲームのような」「◯◯のキャラ」と既存の作品名・キャラ名を書かない。参考に渡すのは本作の絵だけ。

## 6. 音の方向

- BGM: 地域ごとに 1〜2 曲（4 章の表の感じ）、ボス 3 曲、1 人用ダンジョン 1 曲、タイトル 1 曲、ログイン（キャラ選び）1 曲。合計 約 25 曲。すべてオリジナル（作曲の道具・音楽生成 AI で作る場合も既存の曲名・作品名を指定しない）。1 曲 1〜2 分のループ。
- 効果音: 攻撃（武器ごと）・魔法（属性ごと）・当たる・敵の倒れ（大きさで 3 種）・ジャンプ・縄・ポータル・拾う・お金・Lv アップ・転職・書・UI。WebAudio で鳴らす。今の NEON VICE STORY の `src/audio/audio.js` の仕組み（音の合成）を流用し、足りない物は録音・生成。
- 音量は BGM と効果音を別に。ウィンドウを開く音などは小さめ。
