# JOBS — 職業・転職・スキル

> 目次に戻る: [DESIGN.md](DESIGN.md) ／ 計算式は [STATS.md](STATS.md)
> 職名はユーザーの許可どおり一般的な職名を使う。3 次・4 次の職名とスキル名はオリジナル（仮名）。ヘイスト・ヒール・テレポート・ダブルショットは一般的な技名としてそのまま使う。
> 式の中の **x はスキルの Lv**。⌈ ⌉ は切り上げ、⌊ ⌋ は切り捨て。

## 1. 職の系統図

```
初心者（Lv1〜）
├─ 戦士（Lv10・STR35）
│   ├─ ファイター（Lv30・剣/斧）── クルセイダー（Lv70）── チャンピオン（Lv120）
│   ├─ ページ（Lv30・剣/鈍器）──── ナイト（Lv70）──────── パラディン（Lv120）
│   └─ スピアマン（Lv30・槍/矛）── ドラグーン（Lv70）──── ダークナイト（Lv120）
├─ 魔法使い（Lv8・INT20）
│   ├─ ファイアウィザード（火・毒）── ファイアメイジ ── ファイアアークメイジ
│   ├─ アイスウィザード（氷・雷）──── アイスメイジ ──── アイスアークメイジ
│   └─ クレリック（聖・回復）──────── プリースト ────── ビショップ
├─ 弓使い（Lv10・DEX25）
│   ├─ ハンター（弓）────────── レンジャー ──── マスターアーチャー
│   └─ クロスボウマン ────────── スナイパー ──── マークスマン
├─ 盗賊（Lv10・DEX25）
│   ├─ アサシン（クロー）──── ハーミット ──── ナイトストーカー
│   └─ バンディット（短剣）── ローグ ──────── シャドウブレード
└─ 海賊（Lv10・DEX20）
```

- 職は 5 系統・12 の最終職。海賊は「港町の海賊船」で転職する（作る順番では M5 以降に回してもよい。PLAN.md 参照）。
- 一度選んだ職は変えられない（クラシックどおり）。セーブの枠は 6 人まで作れるので、別の職は別のキャラで遊ぶ。キャラ同士は倉庫を共有する（1 人用で「サブキャラ」の楽しみを残す）。

## 2. 能力値（AP）と HP/MP

### 2-1. AP（能力ポイント）

- 最初の能力値: STR・DEX・INT・LUK を「サイコロ」で決める（合計 25、各 4 以上。何度でも振り直せる。クラシックのキャラ作り）。
- Lv が 1 上がるごとに **AP 5**。**自動で振る機能は無い**（クラシックどおり、全部手で振る）。
- 3 次・4 次転職の時に AP +5（記念）。
- 一度振った AP は「AP 振り直しの書」（4 次手前のクエストの報酬で 1 枚、市場でまれに売る）でしか戻せない。
- HP・MP にも AP を振れる（1 AP で HP+ 職ごとの値、または MP+）。振った分は「AP 振り直しの書」で戻せる（いわゆる HP 洗い。1 人用なので強すぎない範囲で残す）。

| 職 | 主ステータス | 副ステータス | 武器に必要 | ふつうの振り方 |
|---|---|---|---|---|
| 戦士 | STR | DEX | STR | DEX を装備に必要な分（Lv×1.0 くらい）、残りは STR |
| 魔法使い | INT | LUK | INT | LUK を装備に必要な分（4〜Lv×0.6）、残りは INT |
| 弓使い | DEX | STR | DEX | STR を装備に必要な分（Lv×0.5）、残りは DEX |
| 盗賊 | LUK | DEX（と STR） | LUK | DEX を Lv×0.6、残りは LUK |
| 海賊（ナックル） | STR | DEX | STR | DEX 少し、残りは STR |
| 海賊（銃） | DEX | STR | DEX | STR 少し、残りは DEX |

### 2-2. HP・MP の上がり方（Lv が 1 上がるごと。幅は乱数）

| 職 | HP | MP | 備考 |
|---|---|---|---|
| 初心者 | 12〜16 | 10〜12 | |
| 戦士 | 24〜28 | 4〜6 | 「最大HPアップ」で +2x（最大 +20） |
| 魔法使い | 10〜14 | 22〜24 ＋ INT÷20 | 「最大MPアップ」で +x（最大 +10）＋ INT÷10 |
| 弓使い | 20〜24 | 14〜16 | |
| 盗賊 | 20〜24 | 14〜16 | |
| 海賊 | 22〜26 | 18〜22 | |

- AP を HP に振った時: 戦士 +20、魔法使い +8、他 +16。MP に振った時: 戦士 +2、魔法使い +18、他 +10。
- 転職の時のボーナス: 1 次 戦士 HP+200〜250、魔法使い MP+100〜150、他 HP+100 MP+25。2 次 戦士 HP+300、魔法使い MP+450、他 HP+300 MP+150。3 次・4 次 は 2 次の 1.5 倍。
- 最初の HP 50・MP 5。

### 2-3. SP（スキルポイント）

| 段階 | もらえる SP | 合計の目安 | 使えるスキル |
|---|---|---|---|
| 初心者 | Lv2〜7 で 1 ずつ | 6 | 初心者のスキル（3 つ、合計最大 9 → 全部は上げられない） |
| 1 次（Lv10〜29） | 転職で 1、以後 Lv ごとに 3（魔法使いは Lv8 から） | 61（魔法使い 67） | 1 次スキル |
| 2 次（Lv30〜69） | 転職で 1、Lv ごとに 3 | 121 | 2 次スキル |
| 3 次（Lv70〜119） | 転職で 1、Lv ごとに 3 | 151 | 3 次スキル |
| 4 次（Lv120〜200） | 転職で 1、Lv ごとに 3 | 241 | 4 次スキル（一部は「極意の書」で上限が 20→30） |

- SP は段階ごとに別の財布。余った SP は次の段階へ持ち越せない（クラシックどおり、2 次になったら 1 次の残りは 1 次のスキルにしか振れない。1 次の SP が残ったまま 2 次になれるが、2 次の SP は 2 次のスキルにだけ）。
- 「SP 振り直しの書」はクエストの報酬（各段階の転職の後に 1 枚）と、市場でまれに売る。
- 4 次の「極意の書」: 4 次のスキルのうち★の付いたものは最大 Lv が最初 10。各スキル専用の「極意の書 20」「極意の書 30」（成功率 70% / 50%、失敗しても無くなるだけ）で上限が上がる。高 Lv のボスと 1 人用ダンジョンが落とす。

## 3. 転職の試験

### 3-1. 1 次（Lv10、魔法使いは Lv8）

| 職 | 場所・転職官 | 条件 | 流れ | もらえる物 |
|---|---|---|---|---|
| 戦士 | ガルド岩台・戦士長ドルガ | Lv10、STR35 | ドルガに話す → 決意を聞かれる → 転職 | 青銅のソード、赤ポーション ×20 |
| 魔法使い | シルワ森都・大魔導師オルフェ | Lv8、INT20 | オルフェに話す → 簡単な魔力の試し（光る玉を 3 つ触る） → 転職 | 麻のワンド、青ポーション ×20 |
| 弓使い | ポム丘・弓の師範エルナ | Lv10、DEX25 | エルナに話す → 的を 1 つ射る → 転職 | 草原の弓、弓の矢 ×2000 |
| 盗賊 | クロウ街・影の頭領ヤミ | Lv10、DEX25 | ヤミの部屋に裏から入る（隠しポータル） → 転職 | 黒布のクロー、投げ星 ×800 ×3 |
| 海賊 | 潮風号・キャプテン・リオ | Lv10、DEX20 | 甲板の小さな試験（樽を 3 つ壊す） → 転職 | 帆布のナックル と 帆布の銃、弾 ×800 |

- 転職すると武器が 1 つもらえ、持ち物の枠が 4 つずつ増える（装備・消費・その他）。
- 1 次の帯（Lv10・魔法使いは Lv8）の武器は、必要な能力値が転職の条件と同じ（戦士 STR35・魔法使い INT20・弓使い DEX25・盗賊 DEX25・海賊 DEX20）。もらってすぐ持てる（盗賊のクローも LUK でなく DEX25）。
- 転職官は自分の系統にしか転職させない（盗賊の転職官の前で戦士にはなれない）。

### 3-2. 2 次（Lv30）— 「試しの珠」

1. 転職官に話す → 「推薦状」をもらう。
2. 試験官（各職の修練場の前にいる）に推薦状を渡す → 修練場（V211・V311・V413・V513・V108）へ入る。
3. 修練場で「試しの魔物」を倒し **試しの珠 30 個**を集める（制限時間 20 分。時間切れや外に出るとやり直し）。
4. 試験官から「試験の証」をもらい、転職官へ戻る → 2 次の職を選ぶ（説明を聞いてから決める。決める前に何度でも聞ける）。

職ごとの味付け（中身は同じ「30 個集める」だが見た目と仕掛けが違う）:

| 職 | 修練場の仕掛け |
|---|---|
| 戦士 | 狭い闘技場。試しの魔物が 2 倍の数で押し寄せる。 |
| 魔法使い | 浮いた足場の部屋。テレポート台（乗ると別の足場へ飛ぶ）。 |
| 弓使い | 動く的（壊すと珠が出る）と魔物が混ざる。遠くの的を狙う練習。 |
| 盗賊 | 暗い倉庫。明かりの近くだけ見える。珠の半分は「鍵のかかった箱」の中（叩くと開く）。 |
| 海賊 | 揺れる甲板。樽を壊すと珠と魔物が出る。 |

### 3-3. 3 次（Lv70）— 「もう一人の自分」と「賢者の石」

1. ヒョウガ村の長老の家（F117）で、自分の系統の長老に話す。
2. 長老の手紙を持って、**大陸の自分の転職官**（2 次と同じ人）に会いに行く → 「心の試練」を受ける。
3. 修験の雪洞（F118）で **もう一人の自分**（M300。自分の 2 次スキルを使う影）を倒す → 「黒いお守り」。制限時間 20 分。
4. ヒョウガ村の上の「賢者の石」（F107 の頂の手前）に「黒いお守り」と「闇の水晶」（ねむり谷の封印の番人シグのクエストでもらう、または素材から作る）を捧げ、**5 問のクイズ**に答える（ゲームの知識を問うオリジナルの問題。30 問から 5 問。間違えたら水晶だけ失ってやり直し）。
5. 長老から 3 次の職へ。AP +5、SP +1。

### 3-4. 4 次（Lv120）— 「紅の印」「蒼の印」

1. 3 次の長老から「推薦状」をもらう（Lv120）。
2. 竜の背の村の竜の聖堂（D115）の大老ヴァルドに推薦状を渡す。
3. 竜の谷の **紅翼の主**（M211・黒い翼の谷）と **蒼翼の主**（M212・骨の谷）を倒し、「紅の印」と「蒼の印」を持ってくる（それぞれ 30 分ごとに出る強敵。1 人で倒せるよう体力・攻撃はふつうの強敵より低い（MONSTERS.md の MOB_TUNE）。試験中は印を必ず落とす）。
4. ヴァルドへ渡す → 4 次の職へ。AP +5、SP +1。4 次の★スキルのうち 1 つの「極意の書 20」をもらう。

## 4. スキル一覧

- 種類: **攻** = 攻撃 / **補** = 補助（自分にかけるバフ。時間が切れると消える） / **常** = 常に効く（パッシブ） / **呼** = 召喚。
- MP は 1 回使う時の消費。「—」は MP 不要（パッシブ）。
- 前提 = このスキルを習うのに必要な、別のスキルの Lv。
- ★ = 4 次の「極意の書」で上限が上がるスキル（最初の最大 Lv / 書を使った後の最大 Lv）。
- 1 人用なので「パーティーにかける」効果はすべて「自分にかける」に変えている。

## 6. スキルの使い方の決まり

- スキルはキーに割り当てて使う（UI.md のキー配置）。攻撃スキルは「攻撃キー」に割り当てることもできる（クラシックの「基本攻撃をスキルに置き換える」遊び方）。
- 待ち時間（クールタイム）は 4 次の一部だけ。1〜3 次は MP だけが制限（クラシックどおり）。
- 補助（バフ）は時間が切れる 5 秒前に画面の右上のアイコンが点滅する。
- 「熟練度」は最小ダメージを決める（STATS.md）。
- 攻撃速度は武器の速さ（速い/普通/遅い）＋加速スキル（+2 段階）で決まる。段階ごとの 1 回の動きの時間は STATS.md。
- 職の武器でない武器を持つと、職のスキルは使えない（クラシックどおり。例: ファイターが槍を持つと剣・斧のスキルは使えない）。
