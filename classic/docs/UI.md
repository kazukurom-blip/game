# UI — 画面と操作

> 目次に戻る: [DESIGN.md](DESIGN.md)
> 画面の基準は 800×600（DESIGN.md 5 章）。ウィンドウの大きさはこの 800×600 の座標で書く。見た目（枠・色・字）はオリジナルのドット絵で作る（クラシックの配置の「分かりやすさ」は参考にするが、形・色・アイコンは写さない）。

## 1. 画面の配置

```
┌──────────────────────────────────────────────── 800 ─┐
│[ミニマップ 160×120]                      [バフのアイコン列]│
│ 地域名 / マップ名                         [クエストのお知らせ]│
│                                                         │
│                     （ゲームの画面）                     │
│                                                         │
│ [システムメッセージ 5 行（拾った物・経験値・クエストの進み）]  │
├─────────────────────────────────────────────────────────┤ 536
│Lv 34 ファイター 名前 │HP ████░ 1234/1500│MP ██░ 120/200│ │ ステータスバー 64px
│[チャット欄 1 行]      │EXP ███░░ 45.12%            │[クイックスロット 8×2]│[メニュー]│
└─────────────────────────────────────────────────────────┘ 600
```

### 1-1. ステータスバー（下、高さ 64）
- 左: Lv（大きな数字）、職名、キャラの名前。
- 中: HP（赤）・MP（青）・EXP（黄）のバー。数値と % を重ねて表示。HP が 20% 以下でバーが点滅。
- 右: クイックスロット（8 マス × 2 段 = 16。キー名が角に小さく出る）。スキル・消費アイテムをドラッグで置く。消費アイテムは残り数を表示。
- 一番右: メニューのボタン（持ち物・装備・ステータス・スキル・クエスト・ワールドマップ・設定）。

### 1-2. 画面の上
- 左上: ミニマップ（M で表示/非表示・大小切り替え）。自分（黄の点）、NPC（緑）、ポータル（青）、クエストの目的の NPC（星）。マップ名と地域名。
- 右上: かかっているバフのアイコン（残り時間を下に。5 秒前から点滅）。その下にクエストのお知らせ（受けられる数・完了できる数）。

### 1-3. 画面の中
- ダメージの数字: 与えた（オレンジ、クリティカルは赤＋小さな星）、受けた（紫）、回復（緑）、MISS。ドット絵の数字のフォント（0〜9 と MISS、大小 2 種）。
- 敵の頭上: 被弾した時だけ HP バー。ボスは画面上に大きな HP バーと名前・段階。
- NPC の頭上: 名前、クエストのマーク（受けられる = 黄色の「？」、報告できる = 光る電球。遠くから分かる大きさで軽く上下に揺れる）。ミニマップの NPC の点も同じ色（受けられる = 黄、報告できる = 白）。
- 拾える物: 地面で上下に小さく揺れる。お金は量で絵が 4 段階。
- Lv が上がった時: 光の柱のエフェクトと「LEVEL UP」の文字、効果音。

### 1-4. チャットとシステムメッセージ
- 1 人用なので「チャット」は自分のメモ・コマンド（/ で始まる）・NPC の一言の欄。Enter で入力。
- システムメッセージ: 拾った物（「◯◯を手に入れた」）、経験値（「経験値 +120」）、お金、クエストの進み（「コロ貝 3/10」）、装備の変化、書の結果。色分けする。
- 吹き出し: NPC や敵がしゃべる時（ボスの段階の変わり目など）頭上に吹き出し。

## 2. ウィンドウ

- ウィンドウはドラッグで動かせる。位置は覚える（セーブ）。Esc で一番上のウィンドウを閉じる。
- 同時にいくつでも開ける。開いている時もゲームは止まらない（クラシックどおり）。設定で「ウィンドウを開くと止まる」に変えられる（1 人用の配慮）。

### 2-1. 装備（E）
- キャラの絵（今の装備の見た目）を中心に、部位のマスを並べる: 帽子・顔飾り・目飾り・耳飾り・上着・下衣（全身）・靴・手袋・マント・盾・武器・指輪 ×2・ペンダント。
- 下にペットの装備のタブ。
- マスにカーソルを当てると説明（名前・必要 Lv/ステータス・性能・強化回数・「上質」）。装備できない物は赤い字。
- ダブルクリックで外す（持ち物へ）。

### 2-2. 持ち物（I）
- タブ 5 つ: 装備 / 消費 / 設置 / その他 / 特別。
- 4 列 × 6〜10 行のマス（タブごとに枠の数が違う）。下にお金。
- 並べ替えのボタン（種類順）。ドラッグで入れ替え、地面へ捨てる（確認）。
- 書を装備に重ねて使う（書をつかんで装備へ）。確認の画面 →成功/失敗の演出。

### 2-3. ステータス（S）
- 名前・職・Lv・経験値・HP/MP・名声（クエストの数）。
- STR・DEX・INT・LUK と、それぞれの横に「＋」ボタン（AP があれば押せる）。HP・MP にも＋。
- 「詳しく」を押すと下に広がる: 攻撃力（最小〜最大）・魔力・物理防御・魔法防御・命中・回避・速さ・ジャンプ・クリティカル率。
- 自動で振る機能は無い（クラシックどおり）。

### 2-4. スキル（K）
- タブ: 初心者 / 1 次 / 2 次 / 3 次 / 4 次（なった段階まで）。
- 1 行に 1 つ: アイコン・名前・今の Lv / 最大 Lv・「＋」ボタン。前提が足りないスキルは灰色で、前提を説明に出す。
- カーソルを当てると「今の Lv の効果」と「次の Lv の効果」を両方表示（JOBS.md の式から計算）。
- アイコンをクイックスロットへドラッグで置く。
- 右上に残りの SP。

### 2-5. クエスト（Q）
- タブ: 進行中 / 完了 / 受けられる（今の Lv で）。
- 進行中: 名前、依頼者、目的の進み（コロ貝 3/10 など）、「あきらめる」ボタン。
- 依頼者の場所へ印を付けるボタン（ミニマップとワールドマップに星）。

### 2-6. ワールドマップ（W）
- 地域ごとの絵地図。マップのアイコン（町・狩り場・ボス）とつながり。自分の位置が光る。
- マップにカーソル: 名前・推奨 Lv・出る敵（会ったことのある敵だけ。会っていないのは「？」）。
- 地域の切り替えのタブ（ヴェルデ大陸 / 空と雪 / おもちゃと海 / 竜と神殿 / 星の果て）。
- **試遊版（W）**: 地域（WORLD.md の 10 地域）のタブ → その地域の絵地図。点は町（四角・大きめ）・狩り場（丸）・洞くつ/特別（丸）・ボスの間（三角）・ジャンプの試練（ひし形）、線はポータルのつながり（点線は乗り物）、地域の外へのつながりは「→地域」。今いるマップは点滅する輪。受けられるクエストの依頼者がいるマップに「？」、報告できる所に電球、進めているクエストの目的地（倒す敵の出る所・行く所・話す相手・調べる物）に「★」。マウスを乗せると名前・Lv 帯・出る敵（会ったことのある敵だけ。ほかは「？」）・曲の名前。行ったことのない所は「？？？」。データ（位置・つながり）は `classic-unity/Data/worldmap.json`（Unity でも使う）、印は Core の `GameSession.WorldMarks()`。

### 2-7. ミニマップ
- 1-2 のとおり。大きくした時は足場と縄の線も描く。

### 2-8. 敵の図鑑（B。試遊版は L）
- 倒した敵の絵・Lv・HP・出るマップ・落とす物（落としたことのある物だけ表示）。全部そろえると称号。
- 1 人用の「集める楽しみ」。
- **カード集め（試遊版で入れた形）**: 敵はまれに「その敵のカード」を落とす（拾うと図鑑へ。1 種類 5 枚で完成）。窓は地域のタブ → カードの並び（5 つの印で枚数。会っていない敵はシルエットと「？？？」）→ クリックで Lv・HP・倒した数・出る所。上に図鑑の段・完成の数・今の上乗せと次の段まで。地域を全部完成させると勲章。数値は ITEMS.md 9 章。

### 2-10. 勲章（試遊版は N）
- 手に入れた勲章とまだの物（条件のヒントと進み「12/100」）。組（成長・討伐・旅・依頼・図鑑・書と財・試練・そのほか・クエスト）ごとに並べ、「全部 / 持っている / まだ」のタブ。
- 1 つだけ付けられる（装備の欄「メダル」と同じ。能力は重ならない）。付けると名前の上に金色の札。勲章を手に入れると大きな知らせ。ITEMS.md 8・9 章。

### 2-11. 記録と統計（試遊版は U）
- 遊んだ時間・倒した敵の数と種類・ボスを倒した回数と種類・倒れた回数・最大ダメージ・拾ったお金・一番多かったお金・拾った品・飲んだ薬・書の成功/失敗/壊れた・最高の強化・ダンジョン・訪ねたマップと町・隠し部屋・カード・勲章の数・ボスの最短撃破（最初に攻撃してから倒すまで）。
- タブ「ジャンプの試練」（登った回数・最短）・「椅子」（集めた椅子の一覧。持ったことの無い椅子は「？？？」）。

### 2-9. 設定（Esc を長押し、またはメニュー）
- キー配置（3 章）、音量（BGM・効果音）、画面の倍率（×1 / ×2 / ぴったり）、ダメージの数字の表示、ウィンドウを開くと止まるか、自動で薬を使う割合（ペットの技）、セーブ・タイトルへ戻る。

## 3. キー配置（初期値。全部変えられる）

| キー | 動き |
|---|---|
| ← → | 歩く |
| ↑ | 縄・はしごにつかまる・上る / ポータルに入る |
| ↓ | 伏せる（伏せたまま攻撃 = 伏せ突き） / 縄・はしごを下りる / 浮いた足場から下りる（↓＋ジャンプ） |
| Alt | ジャンプ |
| Ctrl | 攻撃（ふつうの攻撃） |
| Z | 拾う（押しっぱなしで続けて拾う） |
| Space | NPC と話す（近くの NPC）・会話を進める |
| Shift / Ins / Home / PgUp / Del / End / PgDn / A | スキル・アイテムのクイックスロット（上の段） |
| 1〜8 | クイックスロット（下の段） |
| I | 持ち物 |
| E | 装備 |
| S | ステータス |
| K | スキル |
| Q | クエスト |
| W | ワールドマップ |
| M | ミニマップ |
| B | 敵の図鑑（試遊版は L。B はクイックスロット） |
| N | 勲章（試遊版） |
| U | 記録と統計（試遊版） |
| Enter | チャット欄 |
| Esc | ウィンドウを閉じる / メニュー |
| F12 | 画面写真 |

- **ブラウザの試遊版（`classic-unity/Web/`）の配置**: 図鑑 = **L**・勲章 = **N**・記録 = **U**・全体マップ = **W**（B はクイックスロットに使っているので図鑑は L）。話す = **V**（近くの NPC・調べる物。会話の窓が開いている間は V で光っているボタンを押す、↑↓ で選ぶ、Enter も同じ、Esc で閉じる。会話の間は主人公は動かない）。ジャンプ = Alt・Space・C、攻撃 = Ctrl・X、クイックスロット = Shift A D F G **T** B Y・1〜8（V を話すに使うので 6 番目は T）。
- ノートパソコン用の配置（Ins/Home などが無いキーボード）を 1 つ用意: スキル = A S D F G H、薬 = 1 2 3、ジャンプ = Space（C も可）、攻撃 = X、拾う = Z、話す = E。設定で切り替え。
- キー配置の画面: キーボードの絵の上に、スキル・アイテム・機能のアイコンをドラッグで置く（クラシックの「キー設定」と同じ遊び方。見た目はオリジナル）。

## 4. NPC との会話

```
┌──────────────────────────────────────────────┐
│ [NPC の顔 96×96]  名前                          │
│                  会話の文（1 ページ 4 行まで）     │
│                                                │
│  [選択肢 1]                                     │
│  [選択肢 2]                                     │
│                           [前へ] [次へ] [やめる] │
└──────────────────────────────────────────────┘
```
- 種類: ふつう（次へ） / はい・いいえ / 選択肢（最大 8 行、スクロール） / 数の入力（何個買う、PQ1 の答え） / 文字の入力（クイズ）。
- クエストの受け・報告もこの形。報酬は会話の最後に絵で並べる（経験値・お金・品）。
- 文字は 1 文字ずつ出る（Space で全部出す）。
- **キーだけで進める**: 話すキーを押し続けるだけで「話しかける → 話を聞く → 受ける → さようなら」まで進む。光っているボタンが押される物で、決まりの順は「報告できるクエスト → 受けられるクエストの話を聞く → （クエストの話の画面で）受ける → さようなら」。↑↓ で選ぶボタンを変えられる。
- **NPC の一言**: 話しかけるたびに変わる（NPC ごとに 3〜6 個。島の人と町の主な人は専用、ほかは地域と役から選ぶ組。Lv・転職・クリアしたクエストで変わる一言もある）。進めているクエストの依頼者・報告先に話すと、残りを言う（「コロ貝の殻を、あと 3 個。待ってるよ。」）。データは `classic-unity/Data/tools/world/npc_lines.mjs` → `npcs.json` の `lines`。
- NPC の顔はドット絵（96×96、表情 3 つ: ふつう・笑う・困る）。

## 5. 店

```
┌───────────── 店（NPC の名前） ─────────────┐
│ [店の品]               │ [自分の持ち物]          │
│ タブ: 装備/消費/設置/その他 │ タブ: 装備/消費/設置/その他 │
│ アイコン 名前  値段      │ アイコン 名前  売値       │
│ …                      │ …                       │
│ [買う]                  │ [売る]   [詰め直し]       │
│ お金: 123,456 ルド                                │
└───────────────────────────────────────────┘
```
- 品をダブルクリック → 数の入力 → 確認。
- 装備できない物は赤い字。自分の装備より強い物に小さな「↑」。
- 売値は店の値段の 1/5（装備）・1/2（消費）。
- 詰め直し（投げ星・弾）: 減った分を 1/2 の値段で戻す。

## 7. その他の画面

- **タイトル**: 新しく始める / 続ける（セーブの枠 6 つ。キャラの絵・名前・職・Lv・遊んだ時間）/ 設定。
- **キャラ作り**: 名前、性別、顔（8）、髪型（10）、髪の色（8）、肌の色（4）、最初の服（上下各 2）。最後に能力値のサイコロ（JOBS.md 2-1）。
- **死んだ時**: 画面が暗くなり「町へ戻る」ボタン。失った経験値を表示。墓石が落ちる演出（オリジナルの形）。
- **書の結果**: 成功（明るい光と上がる音）・失敗（暗い煙）・壊れた（割れる演出）。
- **転職**: 光のエフェクト、職名が大きく出る。
- **1 人用ダンジョン**: 画面の上に残り時間と今の部屋の課題。
- **ボス**: 画面の上に大きな HP バー・段階・残り時間。

## 8. 効果音（UI）

ボタンを押す・ウィンドウを開く/閉じる・アイテムを拾う・お金を拾う・装備を変える・Lv アップ・クエストを受ける/完了・書の成功/失敗・店で買う・エラー（できない）。すべてオリジナルの音（DESIGN.md 6 章）。
