# FEEL — 手触りの数値の表

> 目次に戻る: [DESIGN.md](DESIGN.md)
> 「見た目・動き・スキルはクラシックに似ていないと意味がない」ための、動きの数値の決まり。
> **ゲームの数値の出どころは `classic/src/engine/feel.js` の 1 か所**。この表を直したら feel.js も直し、`node classic/tests/physics_unit.mjs` で確かめる。
> 単位: px は内部解像度 800×600 の 1 ドット。速さ px/秒、加速 px/秒²。物理は 60 回/秒の固定（1 フレーム = 1/60 秒）。

## 根拠の種類

| 印 | 意味 |
|---|---|
| **知** | クラシックの動きとして広く知られている値（ファンの解説・再現の試みで共有されている「速さ 100 で歩く 125 px/秒、ジャンプの初速 555、重力 2000、落下の上限 670」などの物理の定数）。Nexon のデータは使っていない。数値は公開の場でよく言われる値を参考にした |
| **似** | 公の値が見つからない所。クラシックの手触り（見た感じ・体感の時間）に似せて決めた値。遊んで直す |
| **設** | 設計書（DESIGN.md・PLAN.md）で決めた値 |

能力値「速さ」「ジャンプ」は 100 が基準（装備・スキルで 速さ 最大 140・ジャンプ 最大 123）。速さは歩く・縄の速さに、ジャンプは初速に、そのまま割合でかかる（`moveStats()`）。

## 1. 地上

| 項目 | 値 | 根拠 | 手触り |
|---|---|---|---|
| 歩く最高速 | **125 px/秒**（速さ 100） | 知 | 画面の横 800 px を 6.4 秒 |
| 押した時の加速 | 1400 px/秒² | 知（歩く力 140000 ÷ 体重 100 と言われる値） | 約 0.09 秒（5〜6 フレーム）で最高速。ほぼすぐ |
| 離した時の減速 | 800 px/秒² | 知（歩きの抵抗 80000 ÷ 100） | 約 0.16 秒で止まり、**約 10 px すべる**（クラシックの「ちょっとすべって止まる」） |
| 逆を押した時 | 2200 px/秒²（加速＋減速） | 似 | 振り向きは速い |
| 坂 | 線にそって進む（横の速さは cos 倍） | 似 | 26° の坂で横 112 px/秒。坂で足が浮かない |
| 伏せ（↓） | その場で止まる（減速 2400） | 似 | 伏せたまま歩けない |

## 2. 空中（ジャンプ・落下）

| 項目 | 値 | 根拠 | 手触り |
|---|---|---|---|
| ジャンプの初速 | **555 px/秒**（ジャンプ 100） | 知 | |
| 重力 | **2000 px/秒²** | 知 | |
| 最高の高さ | **約 77 px**（555² ÷ 2 ÷ 2000） | 知（計算） | 主人公（約 51 px）の 1.5 倍。**段差 64 px は跳んで上がれる、80 px 以上は縄・はしご**（マップの決まり） |
| 滞空 | 約 0.56 秒（同じ高さに戻るまで） | 知（計算） | |
| 落下の最大速度 | **670 px/秒** | 知 | 高い所から落ちても速くなりすぎない（0.34 秒で上限） |
| 空中の左右 | 加速 100 px/秒²、上限は歩く最高速 | 知（空中の抵抗 10000 ÷ 100 と言われる値） | **空中ではほとんど曲がれない**。その場ジャンプ中に → を押しても約 15 px。走りジャンプで逆を押しても勢いはほぼそのまま（クラシックの一番の特徴） |
| 空中の向き | 変えられる | 知 | 振り返って攻撃できる |
| 押しっぱなし | 着地のたびに跳ぶ | 知 | ジャンプのキーを押したままで連続ジャンプ |
| 横の勢い | 空中では減らない | 知 | 走りジャンプの飛距離 約 55 px（段の上へ） |
| 着地 | 線を上から下へまたいだ時だけ | 知 | 浮いた足場は下からすり抜けて上に乗れる |

## 3. 縄・はしご

| 項目 | 値 | 根拠 | 手触り |
|---|---|---|---|
| 上り下りの速さ | **90 px/秒**（速さ 100） | 設（DESIGN.md 3 章）・似 | 歩くより少し遅い |
| つかまる | ↑（地上でも空中でも）。縄の中心から左右 10 px 以内（はしごは 14 px） | 知（↑でつかまる）・似（幅） | ジャンプ中に縄の近くで ↑ を押すと、とびつく |
| 下端より下から | 足元が下端の 28 px 下までなら ↑ でつかまれる（下端まで体が上がる） | 似 | 地面から少し浮いた縄にも届く |
| 上の足場から | ↓ を押すと、足元の縄・はしごの上端（±6 px）につかまって降りる | 知 | |
| 上りきる | 上端に足場があれば、その上に立つ | 知 | |
| 下りきる | 下端で手を離して落ちる | 知 | |
| 離れる | **左右＋ジャンプ**で飛び降りる（横 100・上 370 px/秒 → 約 34 px 跳ねる）。ジャンプだけでは離れない | 知（左右が要る）・似（速さ） | |
| つかみ直し | 飛び降りてから 0.25 秒はつかまれない | 似 | 飛び降りた直後にまたつかまってしまうのを防ぐ |
| つかまっている間 | 攻撃できない・絵は背中向き。動いていない時はコマが止まる | 知 | |

## 4. 足場

| 項目 | 値 | 根拠 |
|---|---|---|
| 形 | **つながった線（折れ線）**。点は左から右へ。線分ごとに prev/next でつながる | 知（クラシックの足場の考え方） |
| 坂 | 線分の傾き。上も下も線にそって歩く | 知 |
| 浮いた足場 | 下からすり抜け・上に乗る。厚さ 16 px（絵だけ） | 知・設 |
| ↓＋ジャンプ | 浮いた足場から降りる。小さく跳ねて（200 px/秒 → 約 10 px）、その足場を 0.35 秒すり抜ける。**下に足場が無い（一番下の地面）時は降りない**（伏せのまま） | 知・似（跳ねの高さ） |
| 端 | 線の端まで歩くと落ちる。横の速さはそのまま | 知 |
| マップの端 | 左右の端で止まる（当たりの半分の幅 12 px） | 似 |

## 5. 被弾

| 項目 | 値 | 根拠 |
|---|---|---|
| ふっとび | 敵と反対へ 横 150・上 280 px/秒（約 20 px 浮いて、約 70 px 下がる） | 似 |

## 6. ダメージの数字（次の段階で作る。決まりだけ）

| 項目 | 値 | 根拠 |
|---|---|---|
| 色 | 与えた: オレンジ、クリティカル: 赤＋小さな星、受けた: 紫、回復: 緑、MISS: 灰の字 | 設（UI.md 1-3） |
| 出方 | 当たった敵の頭の上に出て、**ゆっくり上へ 約 30 px**（1 秒）。最初の 0.1 秒で少し大きく出て元の大きさへ | 似 |
| 重なり | 1 回の攻撃で何回も当たる時は、数字を **縦に積む**（1 つ 18 px 上へ）。少しずつ時間をずらして出す（0.05 秒） | 知（クラシックの積み上がる数字） |
| 消え方 | 0.6 秒たったら 0.4 秒で消える（ドットの間引きで消す。半透明でもよい: エフェクトの層） | 似 |
| 字 | ドット絵の数字（大小 2 種）。1 桁 12×16 前後、桁の間を少し詰める | 設 |

## 7. 攻撃の振り（次の段階で作る。決まりだけ）

| 武器の速さ（段階） | 表示 | ふつうの攻撃 1 回の時間 | 根拠 |
|---|---|---|---|
| 2 / 3 | より速い | 0.48 / 0.54 秒 | 似（段階の名前と 2〜9 の幅は知） |
| 4 / 5 | 速い | 0.60 / 0.66 秒 | 似 |
| 6 | ふつう | 0.72 秒 | 似 |
| 7 / 8 | 遅い | 0.78 / 0.84 秒 | 似 |
| 9 | より遅い | 0.90 秒 | 似 |

- 速くするスキル（ブースター）は 2 段階速く。下限は 2。
- 振りのコマ: 振り上げ → 振り下ろし → 戻り（3 コマ）。当たりの判定は 2 コマ目の始め。
- 地上で攻撃中は歩けない（止まる）。空中で攻撃しても勢いはそのまま。縄・はしごでは攻撃できない。

## 9. 敵（次の段階で作る。決まりだけ）

| 項目 | 値 | 根拠 |
|---|---|---|
| 歩き回り | 1〜3 秒歩く → 1〜3 秒止まる、をくり返す。足場の端・壁で向きを変える（足場から落ちない） | 知 |
| 歩く速さ | 敵の「速さ」（-50〜+50）で 50〜150 px/秒の幅。ふつうの敵は 60〜90 | 似 |
| 追いかけ | 攻撃されたら主人公の方を向いて歩く（追う）。しばらく（5 秒）当たらなければ元の歩き回りに | 知 |
| 触れる | 敵に触れると被弾（5 章）。敵は止まらない | 知 |
| ふっとび | 1 回で敵の HP の一定以上（「押される量」）のダメージで、少し後ろへ（約 10〜20 px・0.2 秒）。被弾のコマ 1 枚（0.3 秒） | 知（押される仕組み）・似（距離） |
| 倒れ方 | 倒れのコマを流しながら **0.6 秒で消える**（点滅でなく、ドットの間引きか半透明: エフェクトの層） | 知・似 |
| ドロップのはじけ方 | 倒れた位置から **上へ跳ねて（約 40 px）落ちる**。複数の時は左右に **約 25 px おき**、中央 → 右 → 左 → 右… の順に 0.05 秒ずつずらして出す。地面では上下に小さく揺れる（3 px・1.2 秒の周期） | 知（並び方）・似（高さ・時間） |
| お金 | 量で 4 段階の絵（ブロンズ・シルバー・ゴールド・束）、くるくる回るコマ | 設 |

## 11. 確かめ方

- `node classic/tests/physics_unit.mjs` — この表の数値（最高速・すべり・高さ・滞空・落下・空中の左右・縄・はしご・下ジャンプ・坂・被弾・1 分間のすり抜けなし）。
- `node classic/tests/avatar_unit.mjs` — 主人公の絵の決まり（14 層・64×80 の枠・高さ・コマ数・半透明なし）。
- `node classic/tests/shots.mjs` — 画面の写真（PORT=8701）。`classic/tests/screenshots/`。
- 遊んで確かめる: `cd classic && npx http-server . -p 8701` → `http://127.0.0.1:8701/`（`?debug` か F2 で足場の線・速さを表示）。
