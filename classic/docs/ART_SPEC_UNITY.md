# オリジナルのドット絵 依頼書（Unity 版・主人公の着せ替え部品）

この文書は、Unity 版「ルミナリア・クラシック」の主人公を**オリジナルのドット絵**で作るための決まりです。部品の分け方・基準点・動きの種類は、いま Unity 側で作っている合成の仕組み（部品を基準点で重ねる方式）に合わせています。

## 0. いちばん大事な決まり（権利）

- **実在のゲームの画像（Downloads などにある抜き出し素材）は、使わない・写さない・手直ししない。**
  - プロジェクトに入れない。入っている物は外す。
  - 横に置いて見ながら同じ形を描く、なぞる、色だけ変える、一部だけ差し替える、も全部だめ。
- 使ってよいのは**仕組み**だけ：部品の分け方、重ねる順番、基準点の名前と役目、動きの種類とコマ数、大きさの数値。
- 絵は全部、一から描いたオリジナル。形・顔・髪型・服のデザインは独自のもの。

## 1. 大きさと見え方

| 項目 | 値 |
|---|---|
| 画面の基準 | 800×600（Unity では Pixel Perfect Camera、Reference Resolution 800×600、Assets PPU = 1） |
| 主人公の高さ | 頭のてっぺん〜足の裏 **約 64px**（髪・帽子は含まない） |
| 頭身 | 約 2.5（頭 ≒ 全身の 4 割） |
| 1 コマの枠 | 部品ごとの PNG は**余白を切り詰めて**よい（基準点で位置を合わせるため）。全身を並べた見本は 96×96 の枠 |
| 向き | **左向きを基本**に描く（右向きは左右反転で作る） |
| 色 | 1 部品 16 色まで。全体の基準パレットは 64 色（`palette.png` を一緒に作って固定する） |
| 線 | 外側の線は 1px、その部分の色を濃くした色（真っ黒にしない） |
| 影・光 | 光は左上から。塗りは基本の色＋影＋明るい所の 3 段。網かけ（ディザ）・半透明・ぼかしは使わない |
| 背景 | 透明（PNG のアルファは 0 か 255 だけ） |

## 2. 部品と基準点

部品ごとに **PNG 1 枚＋基準点の JSON** を作る。基準点は、その PNG の左上を (0,0) とした画素の位置（x 右・y 下が正）。

| 部品 | 必ず持つ基準点 | 役目 |
|---|---|---|
| 素体の胴（body） | `origin`（足元の中央）・`navel`（へそ）・`neck`（首の付け根）・`hand`（前の手） | キャラの位置の基準。ほかの部品をつなぐ親 |
| 腕（arm） | `navel`・`hand` | 胴の navel に合わせる。武器は hand に合わせる |
| 頭（head） | `neck`・`brow`（眉間） | 胴の neck に合わせる。顔・髪・帽子は brow に合わせる |
| 顔（face） | `brow` | 頭の brow に合わせる |
| 髪（hair）・後ろ髪（hairBack） | `brow` | 頭の brow に合わせる |
| 帽子（cap） | `brow` | 頭の brow に合わせる |
| 上着（coat） | `navel` | 胴の navel に合わせる（袖は腕の上に重なる部品 `coatArm` を別に） |
| ズボン（pants） | `navel` | 胴の navel に合わせる |
| 靴（shoes） | `navel` | 胴の navel に合わせる |
| 武器（weapon） | `hand` | 腕の hand に合わせる |

JSON の例（`body_stand1_0.json`）:

```json
{ "part": "body", "motion": "stand1", "frame": 0, "png": "body_stand1_0.png",
  "points": { "origin": [22, 61], "navel": [21, 36], "neck": [22, 24], "hand": [10, 39] },
  "delay_ms": 500 }
```

## 3. 重ねる順番（奥 → 手前）

1. 後ろ髪（hairBack）
2. 武器（両手で背中側に来るコマだけ）
3. 素体の胴（body）
4. 靴（shoes）
5. ズボン（pants）
6. 上着（coat）
7. 頭（head）
8. 顔（face）
9. 髪（hair）
10. 帽子（cap）
11. 腕（arm）
12. 上着の袖（coatArm）
13. 武器（weapon。ふつうはここ）

はしご・縄（背中向き）は別の順番（頭・髪が手前、顔は描かない）。

## 4. 動きとコマ

| 動き | コマ数 | 1 コマの時間 | 中身 |
|---|---|---|---|
| stand1（立ち） | 3 | 500ms | 片手に武器。息をするように体がわずかに上下 |
| walk1（歩き） | 4 | 180ms | 体が上下に弾む。腕と脚を大きめに振る |
| jump（ジャンプ） | 1 | — | 脚を曲げ、腕を広げる |
| ladder（はしご） | 2 | 250ms | 背中向き。手足を交互に |
| rope（縄） | 2 | 250ms | 背中向き。縄を両手でつかむ |
| alert（戦闘の構え） | 3 | 500ms | 武器を前に構える。少し前かがみ |
| swingO1（片手の振り下ろし） | 3 | 300 / 150 / 350ms | 振りかぶる → 振り下ろす（当たる）→ 戻す |
| prone（伏せ） | 1 | — | 地面に伏せる（↓） |

まず上の 8 つ（合計 19 コマ）を作る。部品ごとに、全部のコマ分の PNG と JSON を描く（動かない部品も、コマごとに位置が違えば JSON を分ける）。

## 5. 最初に作る 1 体（スターター）

| 部品 | 中身（オリジナルのデザイン） |
|---|---|
| 素体 | 肌の色の体（インナーなし）。手は軽く握る |
| 頭・顔 | 大きめの目、小さな口。表情は「ふつう」1 種 |
| 髪 | 短めの前髪＋後ろ髪 |
| 上着 | 生成りの半袖シャツ |
| ズボン | 茶色の短パン |
| 靴 | 茶色の布靴 |
| 剣 | 木の剣（片手） |

## 6. ファイルの置き方（Unity）

```
Assets/Art/Character/Starter/<part>/<part>_<motion>_<frame>.png
Assets/Art/Character/Starter/<part>/<part>_<motion>_<frame>.json
Assets/Art/Character/palette.png
```

- 取り込みの設定：Texture Type = Sprite (2D and UI)、Pixels Per Unit = 1、Filter Mode = Point、Compression = None、Generate Mip Maps = Off。
- Downloads の元の素材フォルダは、プロジェクトの外に置いたまま触らない（参照もしない）。

## 7. 進め方と確認

1. まず **stand1 の 1 コマ目だけ**、全部の部品を描いて合成した全身の見本を見せる（ユーザーの確認）。
2. OK なら stand1 の残り → walk1 → jump → ladder・rope → alert → swingO1 → prone の順に描く。
3. 1 つの動きができるたびに、Unity で動かした動画かコマ並べを見せる。
4. 確認すること：
   - 実在のゲームの絵と同じ形・同じ顔・同じ髪型になっていないか（似ていたら描き直す）
   - 基準点でつないだとき、首・腰・手首・足首にすき間や段差が出ないか
   - 64 色のパレット・1 部品 16 色・半透明なし・外側の線 1px が守られているか
