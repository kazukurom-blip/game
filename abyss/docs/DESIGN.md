# ABYSS DROP — 設計書（遊びの中身と目標の数）

> 空から灰が降った日、大地に「深淵（アビス）」が口を開けた。底から湧く魔物を斬り、落ちる宝を拾い、さらに深くへ。
> 放置で戦い続け、ランダムなレアリティの装備を集め、厳選し、鍛え、転生してまた潜る。

調べた人気作の仕組みは `docs/REFERENCE.md`。名前・絵は既存の作品から借りない（仕組みだけ取り入れる）。

## 1. 遊びの輪
1. **放置で戦う**: 主人公は自動で歩き、スキルバーの左から自動でスキルを使う。オフラインでも稼ぐ（上限 8 時間〜、転生で延びる）。
2. **拾う**: 8 段階のレアリティ（ノーマル/マジック/レア/エピック/レジェンダリー/セット/ユニーク/ミシック）＋覚醒・極致。光の柱・音・知らせで盛り上げる。
3. **厳選と比較**: 実際の計算で「火力 ▲12% / 耐久 ▼3%」を出す。自動の振り分け（分解・残す・自動装備）で放置でも散らからない。
4. **鍛える**: 強化 +1〜+20（失敗あり・天井あり）、オプションの付け替え、混沌の振り直し、レアリティ昇格、ソケット、宝石の合成、ルーン語、伝説の力の抽出と装着、商人の目利き（ガチャ）。
5. **深く潜る**: 10 章 × 5 地域 × 10 ステージ → 魔境 I〜XVI → 深淵の裂け目（段階は上限なし）。
6. **永続の強化**: パッシブの星座盤、アビスLv（Lv100 以降・上限なし）、転生（魂の祭壇）、実績、魔物図鑑、宝物図鑑、ペット。
7. **毎日の楽しみ**: 日課の懸賞（毎日 3 つ＋毎週 1 つ）、ログインの贈り物、週末の祭（宝ゴブリンが増える）。

## 3. 進み具合の目安（1 周目）
- Lv10: 約 20〜25 分 / 第一章クリア: 約 30〜50 分 / 第五章（最初の転生の解放）: 約 7〜10 時間 / 第十章: 約 33〜43 時間。（「敵が弱すぎる・ヌルゲー」の声で敵を硬くしてから。BALANCE §15）
- 2 周目以降は転生の強化で 3 倍以上速く。魔境と裂け目は数十〜数百時間の遊び。
- レジェンダリー以上: 序盤は 5〜10 分に 1 つ、終盤は 1〜2 分に 1 つ。ミシックは 1 周に数個。
- ボスの壁は「少し稼げば越えられる」程度（10〜20 分）。越えられないときは何をすればよいか（装備・スキル・強化）を知らせる。
- 数字はインフレを楽しむ。序盤から 2〜3 桁、終盤は 億・兆・京。

## 4. 言葉の決まり
- レアリティ: ノーマル / マジック / レア / エピック / レジェンダリー / セット / ユニーク / ミシック。品質: 覚醒 / 極致。
- 数字: 既定は日本式（1.23万・4.56億・7.8兆）。設定で K/M/B・指数に変えられる。
- 名前は和風と洋風のまざったダークファンタジー。既存作品の固有名詞（アイテム名・キャラ名・地名）を使わない。
- 説明文は短く、数字を必ず入れる（「ダメージ +25%」「3 秒ごとに」）。

## 5. 画像の差し替え
- 絵はすべて枠 ID を持つ。ゲームの「画像」の窓、または `assets/custom/` に置いて差し替える（`docs/ASSETS.md`）。
- AI で作るための指示文（英語・日本語）とサイズ・向き・背景の決まりは `docs/AI_PROMPTS.md`。
- 1 枚絵で動くように作る（変形で動かす）。コマ送りの横並び画像にも対応。背景は単色なら自動で抜ける。

## 6. 収益化について
- 課金なし。広告なし。時間を買う仕組みもない（倍速は自由）。商品として売る場合は買い切りを想定。
