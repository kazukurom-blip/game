# 画像の差し替えの手引き（ABYSS DROP）

ABYSS DROP の絵は、すべて**ほかの AI（ChatGPT・Midjourney・Stable Diffusion・FLUX・NovelAI など）で作った画像に差し替え**られます。
主人公・鎧を着た姿・武器・兜・敵・ボス・召喚物・ペット・スキルの演出・アイコン・背景・ロゴ・タイトル画面まで、絵の 1 つ 1 つに名前（**枠 ID**）があり、
その枠に画像を入れると、戦闘の画面・装備の窓・持ち物・説明の窓・タイトル画面のどこでも、すぐにその画像が使われます。

- いちばん簡単な方法: ゲームの右の窓の「🖼 画像」→ 枠のカードを押す →「AI で作る」の指示文をコピーして AI で作る → できた画像をその窓に落とす → 「保存して使う」。
- 枠ごとの指示文の一覧: [docs/AI_PROMPTS.md](AI_PROMPTS.md)（表計算ソフトなら `docs/AI_PROMPTS.csv`）
- 型紙（どこに描けばよいかの見本の画像）: `assets/templates/`（ゲームの「型紙を保存」でも作れます）
- 枠の数: **絵 868**（主人公 30・装備（着た姿） 94・敵とボス 160・召喚物とペット 37・スキルの演出 194・アイコン 321・背景 30・画面の飾り 2）＋ **音 102**（効果音 `sfx.*` 87・BGM `bgm.*` 15 → 8-2 章）。
  画面で召喚物の窓を開くと、召喚物の種類の枠がさらに足されます。

---

## 1. しくみ（どの画像が使われるか）

1 つの枠には、次の順番で最初に見つかった画像が使われます。

| 順番 | どこの画像か | 説明 |
|---|---|---|
| 0 | 調整中の下書き | 画像の窓で調整している間だけ。保存しないで閉じると消える |
| 1 | **ゲーム内で入れた画像** | 「画像」の窓で入れた物。このブラウザの中（IndexedDB）に保存される。ほかの人には配られない |
| 2 | **assets/custom/ に置いた画像** | ゲームのフォルダに置いて配る物（`assets/custom/custom.json` に一覧）。→ 8 章 |
| 3 | 予備の枠の画像 | 例: 持ち物のアイコン `icon.item.sword` が無ければ、手に持った姿 `gear.sword` の画像を使う |
| 4 | 親の枠の画像 | ID の末尾を削った枠。例: `fx.enemy.meteor` が無ければ `fx.enemy`（敵の攻撃・全部まとめて） |
| 5 | コードで描いた絵 | 何も無いときの絵（必ず何か出る） |

- 絵は **1 枚の静止画**で動きます（ゲームが揺らす・傾ける・振る）。歩きのコマを何枚も作る必要はありません。横に並べたコマ送りの画像も使えます（6 章）。
- 入れた画像は自動で「背景を抜く → 透明な外側を切る → 足元を合わせる → ゲームで使う大きさに縮める」をします。あとから「調整」で直せます。

## 2. 枠 ID（名前の決まり）

ファイル名は **枠 ID ＋ .png**（例: `monster.ash_wolf.png`）。小文字・英数字・`_`・`.` だけです。

| 枠 ID | 何の絵か | 例 |
|---|---|---|
| `hero.<クラス>.body` | 主人公の体（基本の服） | `hero.warrior.body` |
| `hero.<クラス>.outfit.<スタイル>` | 胴にその鎧を着たときの全身。無ければ体の画像 | `hero.ranger.outfit.leather` |
| `hero.<クラス>.portrait` | クラス選択の立ち絵（背景つきでよい） | `hero.sorcerer.portrait` |
| `gear.<武器の種類>` | 手に持った武器（先が上・柄が下） | `gear.sword`・`gear.bow` |
| `gear.<副手の種類>` | 盾・矢筒・宝珠・魔導書・副刀 | `gear.shield` |
| `gear.helm.<スタイル>` | 兜（コードの絵の体にだけ重なる） | `gear.helm.plate` |
| `gear.<部位>.<スタイル>` | 体に重ねる鎧の部品（任意） | `gear.chest.mail` |
| `gear.u.<ユニーク ID>` | ユニーク・セット・ミシックの武器・副手・兜の見た目 | `gear.u.<id>` |
| `monster.<敵 ID>` | 敵・ボス（左向き） | `monster.rot_zombie`・`monster.boss_butcher` |
| `minion.<種類>` | 召喚物（`minion` だけなら全部まとめて） | `minion.skeleton` |
| `pet.<ペット ID>` | ペット | `pet.emberfox` |
| `fx.<スキル ID>.<部品>` | スキルの演出（下の表） | `fx.s_bolt.proj` |
| `fx.enemy.<種類>` | 敵の弾・攻撃（`fx.enemy` だけなら全部まとめて）。ボスの特技の範囲（`meteor`・`nova`・`pool`・`beam`・`spikes`・`breath`・`quake`・`firewall`・`jail`・`warp`・`mortar`・`blood`・`whirl`）にも枠があります | `fx.enemy.arrow`・`fx.enemy.pool` |
| `fx.pet.<種類>` | ペットの手助け（`proj` 弾・`area` 範囲・`heal` 回復の光） | `fx.pet.heal` |
| `icon.item.<種類>`／`icon.item.<部位>.<スタイル>` | 持ち物のアイコン。無ければ装備の絵 | `icon.item.sword`・`icon.item.helm.plate` |
| `icon.u.<ユニーク ID>` | ユニークのアイコン。無ければ着た姿、それも無ければベースのアイコン | |
| `icon.mat.<素材 ID>`・`icon.skill.<スキル ID>` | 素材・スキルのアイコン | `icon.mat.echo`・`icon.skill.w_slash` |
| `icon.gem.<ID>`・`icon.rune.<ID>`・`icon.support.<ID>` | 宝石・ルーン・補助の刻印（`icon.gem` だけなら全部まとめて） | |
| `bg.<章>`／`bg.<章>.mid`／`bg.<章>.ground` | 背景の奥・中景・地面（章は act1〜act10） | `bg.act3.mid` |
| `ui.logo`・`ui.title` | タイトルロゴ・タイトル画面の背景 | |

**クラス**: `warrior` 剣闘士・`ranger` 狩人・`sorcerer` 魔導士・`necromancer` 死霊術師・`assassin` 影刃
**スタイル（鎧）**: `cloth` 布・`leather` 革・`mail` 鎖・`plate` 板金
**武器**: `sword` 片手剣・`axe` 斧・`mace` 槌・`greatsword` 両手剣・`bow` 弓・`crossbow` 弩・`staff` 杖・`wand` 短杖・`scythe` 大鎌・`rod` 骨杖・`dagger` 短剣・`claw` 鉤爪
**副手**: `shield` 盾・`quiver` 矢筒・`orb` 宝珠・`grimoire` 魔導書・`offblade` 副刀
**部位**: `chest` 胴・`gloves` 手・`belt` 腰・`legs` 脚・`boots` 足

**演出の部品**（スキルの動きごとに使う物だけ枠があります）:

| 部品 | 何か | 部品 | 何か |
|---|---|---|---|
| `proj` | 飛ぶ弾（右向き） | `hit` | 当たった瞬間の火花 |
| `area` | 範囲・爆発（地面） | `swing` | 斬撃・振りの軌跡 |
| `chain` | 連鎖の稲妻（横に伸ばす） | `beam` | 光線（横に伸ばす） |
| `aura` | 足元のオーラ | `buff` | 体を包む強化のオーラ |
| `summon` | 呼び出す魔法陣 | `trap`・`totem` | 罠・トーテム |
| `trail` | 突進の残像 | `curse` | 呪いの紋 |
| `cut` | 奥義のカットイン（画面に大きく出る帯） | | |

全部の枠 ID は、ゲームの「画像」の窓（検索できます）か [AI_PROMPTS.md](AI_PROMPTS.md) にあります。窓の「その他」には、枠の一覧には無いのにゲームの中で使われた ID も出ます。

## 3. 大きさ・縦横比・向き

画像は大きめに作ってかまいません（ゲームが自動で縮めます。1 コマの長い辺 2048 px まで）。小さすぎる画像（短い辺 256 px 未満）はぼやけます。

| 種類 | ゲーム内の大きさ | 作る比 | AI で作る大きさの目安 | 向き | 背景 |
|---|---|---|---|---|---|
| 主人公の体・鎧の姿 | 150×200 | 2:3〜3:4 | 1024×1536（GPT）・832×1216（SDXL） | **右向き**・真横 | 透明 |
| 立ち絵 | 300×420 | 2:3 | 1024×1536 | 自由 | 背景つきでよい |
| 武器（手に持つ） | 110×150 | 2:3 | 1024×1536 | **先が真上・柄が下**（弓・弩は真ん中が握り） | 透明 |
| 副手・兜 | 90×110・80×70 | 1:1 | 1024×1024 | 盾は正面・兜は右向き | 透明 |
| 敵 | 150×150（ボス 240×240） | 1:1〜2:3 | 1024×1024 | **左向き**・真横 | 透明 |
| 召喚物・ペット | 120×140・90×90 | 1:1 | 1024×1024 | 右向き | 透明 |
| スキルの演出 | 弾 90×46・当たり 120×120・範囲 256×256 など | 1:1〜16:9 | 1024×1024 | 弾は右へ飛ぶ向き | **真っ黒** |
| アイコン | 96×96（素材 64×64） | 1:1 | 1024×1024 | 長い物は斜め 45° | 透明（スキルは暗い背景） |
| 背景（奥） | 1280×720 | 16:9 | 1536×1024・1344×768 | — | 画面いっぱい |
| 背景（中景） | 1280×720 | 16:9 | 同上 | — | 上は透明 |
| 背景（地面） | 1280×220 | 約 6:1 | 1536×512 を作って切る | — | 上は透明 |
| ロゴ | 720×240 | 3:1 | 1536×512 | — | 透明 |
| タイトル画面 | 1280×720 | 16:9 | 1536×1024 | — | 画面いっぱい（はみ出た所は切れる） |

- **キャラは 1 枚に 1 体、全身、真横**。周りに 5〜8% の余白。落ち影・地面・文字・枠は入れない。
- ボスの枠（240×240）は細かく描くための大きさです。戦闘の画面では、ボスは普通の敵の**約 1.6〜1.9 倍の高さ**に詰めて描きます（主人公が隠れないように。ボスの大きさのデータ 1.5〜2.3 をそのまま掛けない）。
- 背景・タイトル画面のように大きな枠は、差し替えが無いときのコードの絵を 1 倍の細かさで描きます（ほかは 2 倍）。差し替えの画像には関係ありません。
- 光は正面のやや上から（敵は左右反転して使うことがあるので、横からの強い光は避ける）。
- 向きが逆に出たら、画像の窓の「左右反転」で直せます。

## 4. 基準点とアンカー

- **基準点**: ゲームがその絵を置く点。キャラ・敵は**足の裏**（地面の線に乗る）、武器は**握る所**、弾・演出・アイコンは**中心**。
- **アンカー**（主人公の体だけ）: 体の中の決まった点。ここに装備が付きます。

| アンカー | 既定の位置（体の画像の中の割合） | 付く物 |
|---|---|---|
| 手（hand） | 横 66%・縦 56% | 武器の握り（武器はここを中心に振る） |
| 副手（offhand） | 横 34%・縦 56% | 盾・宝珠・魔導書・副刀 |
| 頭（head） | 横 50%・縦 17% | 兜（コードの絵の体のときだけ） |
| 背中（back） | 横 44%・縦 38% | 矢筒 |
| 胸（chest） | 横 50%・縦 42% | 演出の目安 |

画像の窓の「基準点とアンカー」で、点を選んでから画像を押すと置けます（ドラッグで動かせる・2 倍／3 倍に拡大できる）。
「足元を自動で」は一番下の不透明な行を探します。「アンカーを推定」は手・頭などのだいたいの位置を出します。左の試し表示で、武器が手に付いて振れるか見ながら合わせてください。

武器の画像は**先を真上、柄を下**にして描き、基準点を握る所にします。AI が斜め 45° で描いたときは「回転」を −45° 前後にします。
**弓と弩は基準点が絵の真ん中**（縦 50%）です。弓は縦に立てて真ん中の握り、弩は先（弓の部分）を上にして銃床の真ん中を持ちます。

## 5. 背景を透明にする

いちばんきれいなのは**生成の時点で透明**にすることです。

1. **ChatGPT／GPT Image**: 「背景は透明（透過 PNG）」と書く。API なら `background: "transparent"`・`output_format: "png"`。
2. **透明にできない AI**: 背景を**ムラのない単色の緑 #00FF00**（体が緑・黄緑の敵は**マゼンタ #FF00FF**）にして作り、画像の窓で抜きます。白や黒の背景は、白い服・黒い輪郭まで消えやすいので、キャラには使わないでください。
3. **スキルの演出**は**真っ黒 #000000** の背景で作ります。加算（光を足す重ね方）で描くので、黒は見えなくなります。

画像の窓の「背景を抜く」:

| 項目 | 使い方 |
|---|---|
| 四隅の色を自動で抜く | 四隅の色の中央値を背景の色にする（入れたときに自動で選ばれる） |
| 色を選んで抜く（スポイト） | 画像の消したい色の所を押す。四隅の色がそろっていないときに |
| 許容値 | 大きいほど似た色まで消える（既定 48）。背景が残るなら上げる、体まで消えるなら下げる |
| 縁のなじませ | 縁の 0〜4 px を半透明にして背景の色のにじみを取る |
| つながった所だけ | 外側からつながった背景だけ消す（中の白い歯・緑の宝石は残る） |
| 閉じた穴も消す | 腕と体のすきまなど、囲まれた背景も消す（64 画素以上の所だけ） |
| 黒を透明に | 明るさを透明度に変える（演出を「通常」の重ね方で使うとき） |
| ほぼ黒を真っ黒に | 加算の演出で、四角い箱がうっすら見えるのを防ぐ |

外部の道具で抜くときの注意: rembg は MIT ですが、**既定のモデル（RMBG-2.0）は商用に有料の契約が必要**です。モデルを明示して選んでください（アニメのキャラなら `isnet-anime` など）。`@imgly/background-removal` は AGPL です。
NovelAI の画像は透明チャンネルに情報が入っているので、透明に見えても背景が残っていることがあります（画像の窓の「背景を抜く」を試す）。

## 6. 1 枚絵とコマ送り

- **1 枚絵**（おすすめ）: ゲームが待機の呼吸・歩きの跳ね・攻撃の踏み込みと振り・被弾ののけぞり・倒れを変形でつけます。AI でキャラの歩きのコマを何枚もそろえるのは難しいので、1 枚で作るのが確実です。
- **コマ送り**: 同じ大きさのコマを**横 1 列**に並べた画像。ファイル名に `@コマ数f` を付けると自動で読みます（`fx.s_bolt.proj@8f.png` = 8 コマ、`@6f12` = 6 コマ・1 秒に 12 コマ）。画像の窓の「コマ送り」でも指定できます。演出（炎のゆらぎ・爆発）に向いています。
- 外側を切るときは、全部のコマで同じ外枠を使うのでコマがずれません。

## 7. ゲームの中で入れる（画像の窓）

右の窓の「🖼 画像」を開きます。

- **一覧**: 分類のタブ（主人公・装備・敵・召喚物とペット・スキルの演出・アイコン・背景・画面の飾り・その他）、小分類（クラス・章など）、検索（名前か枠 ID）、「差し替えた物だけ／まだの物だけ」。緑の枠のカードは差し替え中、青い印は assets/custom の画像、紫の印は予備の枠の画像を使っている所。
- **入れ方**（どれでも同じ）:
  - カードの「入れる」でファイルを選ぶ（背景を自動で抜いて、すぐ使う）
  - カードに画像を落とす
  - カードの上にマウスを置いて `Ctrl+V`（コピーした画像を貼り付け）
  - 「まとめて取り込む」で何枚も選ぶ、または窓に何枚も落とす（ファイル名 = 枠 ID。同じ名前の .json があれば設定として使う）。名前の間違いは「もしかして」で案内します
- **調整の窓**（カードを押す）:
  - 試し表示: 主人公・装備は**今の装備の着せ替え**で、待機→歩く→攻撃→詠唱→被弾をくり返す。敵は主人公と並べて大きさを比べる。演出は暗い背景で弾が飛ぶ・当たる・広がる。背景は 3 枚を重ねて横に流す。アイコンは持ち物のマス（レアリティの色）と地面に落ちた姿
  - 「**戦闘画面で見る**」: 窓を一時的に隠して、戦闘の画面で見ます（保存前の下書きのまま）。右下の「◀ 調整に戻る」で戻る
  - 背景を抜く・形（外側を切る・左右反転・上下左右を切る・左右をつなげる・コマ送り）・置き方（大きさ・ずらし・回転・重ね方）・基準点とアンカー
  - 「AI で作る」: その枠の指示文（英語・日本語・Midjourney・SD の否定）と作る大きさ。「コピー」でコピー
  - 「型紙を保存」「型紙を見る」: 位置の目安の画像（ダウンロードできないときは画像を長押し／右クリックで保存）
  - 「保存して使う」で保存。「入れた画像を消す」で元に戻る（assets/custom に画像があればそれ、無ければコードの絵）
- **パック**: 「パックを書き出す」で入れた画像をまとめて 1 つの .json に（別のブラウザ・PC に移せる。元の画像も入れると、あとで背景の抜き方を直せる）。ダウンロードできない環境（ページの中に埋め込まれたときなど）では「文字で表示」→「コピー」してメモ帳などに保存し、「パックを読み込む」で貼り付けます。
- **すべて元に戻す**: ゲーム内で入れた画像を全部消します（assets/custom の画像と音の差し替えは残る）。

入れた画像はこのブラウザの中だけに保存されます。**サイトのデータを消すと消える**ので、ときどきパックを書き出しておくと安心です。

## 8. assets/custom フォルダに置く（ゲームと一緒に配るとき）

1. `assets/custom/` に `枠ID.png` を置きます（フォルダを分けてもよい: `assets/custom/monster/act1/monster.ash_wolf.png`）。
2. `abyss/` の中で `node tools/scan_custom.mjs` を実行すると `assets/custom/custom.json` が作り直されます（知らない ID・重なりも教えてくれます。`--check` で確かめるだけ）。
3. ゲームを開き直すと使われます。ゲーム内で同じ枠に画像を入れていると、そちらが優先されます。

画像と同じ名前の `.json`（例: `hero.warrior.body.json`）を置くと設定になります:

```json
{ "ax": 0.5, "ay": 0.98, "scale": 1.1, "ox": 0, "oy": 0, "rot": -45, "frames": 4, "fps": 12, "blend": "lighter",
  "anchors": { "hand": [0.7, 0.55], "offhand": [0.35, 0.56], "head": [0.5, 0.12], "back": [0.42, 0.36] },
  "bg": "auto", "tol": 48, "trim": true, "flip": true, "crop": { "t": 0, "b": 10 }, "seam": 8 }
```

| 項目 | 意味 |
|---|---|
| `ax`・`ay` | 基準点（0〜1。画像の左上が 0,0） |
| `anchors` | 主人公の体のアンカー（`hand`・`offhand`・`head`・`back`・`chest`） |
| `scale`・`ox`・`oy`・`rot` | 大きさ・ずらし（px）・回転（度） |
| `frames`・`fps` | コマ送りのコマ数・1 秒のコマ数 |
| `blend` | 重ね方（`source-over` 通常・`lighter` 加算・`screen`） |
| `bg`・`tol` | 背景の抜き方（`auto` 四隅の色・`black` 黒を透明に）と許容値 |
| `trim`・`flip`・`crop`・`seam` | 外側を切る・左右反転・上下左右を切る（%）・左右をつなげる（%） |

音の差し替え（サウンドの担当の仕組み）は `assets/custom/audio/<音の ID>.ogg`（mp3・wav も可）に置くと、スキャンで custom.json の `"audio"` にまとめられます。

## 8-2. 音の差し替えの枠（効果音 87・BGM 15）

## 9. AI ごとの作り方

どの AI でも、画像の窓の「AI で作る」の文をそのまま使えます。文には同じ「画風の決まり文」が入っているので、絵柄がそろいます。

### ChatGPT／GPT Image
1. 日本語か英語の指示文を貼り付ける。大きさはキャラ 1024×1536・アイコン 1024×1024・横長 1536×1024。
2. 「背景は透明」が効かないときは「背景を単色の緑 #00FF00 に」と頼む。
3. **鎧の姿**は、承認した体の画像を添付して「同じキャラ・同じポーズ・同じ大きさのまま、服だけ〇〇に」と頼む（`hero.<クラス>.outfit.*` の指示文がその形）。足と頭の位置がずれないか、50% の透明度で重ねて確かめるとよい。

### Midjourney／Niji
1. Midjourney の文（`--ar`・`--style raw`・`--no` 入り）を使う。
2. 絵柄を固定するには、承認した 1 枚を `--sref <画像の URL>` に（強さ `--sw 150〜400`）。同じキャラは（版によって）`--oref`／`--cref`。
3. 背景は単色になるので、画像の窓で「背景を抜く」。

### Stable Diffusion（SDXL 系・Illustrious など）
1. 英語の文（タグにしてもよい）＋否定の文。大きさは 832×1216（縦）・1024×1024。
2. シードを固定すると同じ絵柄で量産しやすい。真横がなかなか出ないときは ControlNet OpenPose（真横の骨格・重み 0.8〜1.0）。
3. 30 枚以上作るなら、承認した 15〜40 枚で絵柄の LoRA を作るとそろう。

### FLUX
1. 英語の文をそのまま（文章で書くのが得意。否定の文は使えない）。大きさは 832×1248 など 16 の倍数。
2. 背景の色（緑・黒）は文に入っています。

### NovelAI
1. 英語の文をタグに直す（`1girl, solo, full body, from side, facing right, ...` のように）。否定の文も使える。
2. 画像の透明チャンネルに生成の情報が入っているので、背景は画像の窓で抜く。

## 10. 絵柄をそろえるコツ

1. 画風の決まり文を変えない（指示文に最初から入っています）。
2. 「見本の 1 枚」（承認した主人公・敵・武器）を作り、編集・`--sref`・IP-Adapter などでいつも参照させる。
3. 種類ごとにシードと縦横比を固定する。
4. 4 枚作って 1 枚残す。チェック: 真横か・全身か・余白はあるか・影はないか・向きは合っているか・手はおかしくないか。
5. 使ったツール・モデル・シード・指示文を残しておく（あとで足すときに同じ絵柄にできる）。

## 11. 権利と商用利用の注意

- **既存のゲーム・アニメのキャラ名、作品名、存命の作家の名前を指示文に入れない**。他人の絵から img2img をしない（似ているかどうか・まねたかどうかで侵害が判断されます）。指示文にもその決まりを入れています。
- AI の出力の扱いはツールごとに違います（2026 年時点の調べ。最新の利用規約を必ず確かめてください）:

| ツール | 出力の扱い | 注意 |
|---|---|---|
| ChatGPT／OpenAI | 利用者が持つ | AI の絵を人が描いたと偽らない |
| Midjourney | 法律の許す範囲で利用者が持つ | 年間売上 100 万ドルを超える会社は Pro 以上。既定では生成物が公開される |
| Stable Diffusion（SDXL の重み） | 出力の権利は主張しない | 用途の制限（ライセンスの付録）を引き継ぐ |
| SD3／3.5 | 年間売上 100 万ドル未満は商用可（要確認） | 売上が増えたら見直す |
| FLUX.1 [schnell]・FLUX.2 [klein] 4B | Apache-2.0 | ゲームに同梱する絵に安全 |
| FLUX.1 [dev]・FLUX.2 [dev] | 非商用のモデルライセンス | 出力の商用利用の解釈がはっきりしない。同梱する絵には使わない |
| コミュニティのモデル・LoRA | モデルごとに違う | 「生成画像の販売可」を 1 つずつ確かめる |
| NovelAI | 商用利用を広く認めている（要確認） | 画像に署名と情報が入っている |

- 日本の考え方（文化庁「AI と著作権に関する考え方について」）では、人の創作的な寄与（細かい指示・選択・手直し）があるときに著作物になりえます。選んで手を加えた絵ほど権利を主張しやすくなります。
- 配る・売るときはクレジットに「アート: AI 補助（使ったツール名）、選定・編集: ○○」のように書くのがおすすめです。
- ゲーム内で入れた画像はそのブラウザの中だけに保存され、ほかの人には配られません。

## 12. 作業の例

### A. 剣闘士の見た目を変える
1. 画像の窓 → 主人公 → 剣闘士 →「剣闘士（体・基本の服）」を押す。
2. 「AI で作る」の日本語の文をコピーして ChatGPT に貼る（1024×1536・透明）。
3. できた画像を調整の窓に落とす。背景が自動で抜け、足元が合います。
4. 試し表示で武器が手に付くか見る。ずれていたら「手（武器）」を選んで画像の手の所を押す。
5. 「保存して使う」。次に「板金の鎧を着た姿」を、保存した体の画像を添付して「服だけ板金の鎧に」で作る（4 つのスタイルぶん）。

### B. 剣を差し替える
1. 装備 → 武器 →「片手剣（手に持った姿）」。指示文で「先が真上・柄が下」の剣を作る。
2. 入れたら基準点を柄の握る所に（試し表示の攻撃で手の中で振れるか確かめる）。斜めの絵なら「回転」で縦に。
3. 持ち物のアイコン（`icon.item.sword`）は、専用の画像を入れなければこの剣の画像が自動で使われます。

### C. 敵を 1 体差し替える
1. 敵・ボス → 第一章 →「敵「灰狼」」。指示文は**左向き**。
2. 体が緑の敵（粘体など）はマゼンタの背景の指示文になっています。
3. 入れたら「戦闘画面で見る」で主人公との大きさを比べ、「大きさ」で合わせる。

### D. スキルの演出を差し替える
1. スキルの演出 → 剣闘士 →「「強打」の斬撃・振りの軌跡」。指示文は**黒い背景**。
2. 入れると重ね方は「加算」になり、黒が消えます。四角い箱が見えるときは「ほぼ黒を真っ黒に」。
3. 炎がゆらぐなどのコマ送りにするなら、横 1 列に並べて `fx.w_slash.swing@6f12.png` のような名前で入れる。

### E. 背景を差し替える
1. 背景 → 第一章。奥（`bg.act1`）・中景（`bg.act1.mid`）・地面（`bg.act1.ground`）の 3 枚。
2. 中景と地面は**上を透明**（または単色の緑）にして作る。継ぎ目が出るときは「左右をつなげる」を 5〜10%。
3. 地面は横に長い帯（1280×220）なので、横長に作って「上を切る」「下を切る」で歩く面が上に来るようにする。
4. 「戦闘画面で見る」でその章へ移動して確かめられます（まだ行けない章は試し表示で）。

### F. ロゴとタイトル画面
- `ui.logo`（文字入りでよい・背景は透明）と `ui.title`（画面いっぱいの絵。はみ出た所は切れる）。タイトル画面に戻ると使われます。

### G. 何十枚もまとめて入れる
1. AI で作った画像の名前を枠 ID に変える（`docs/AI_PROMPTS.csv` の id の列が使えます）。
2. 画像の窓の「まとめて取り込む」で全部選ぶ（または窓に落とす）。名前が違う画像は「もしかして」の案内が出ます。
3. 配るなら `assets/custom/` に置いて `node tools/scan_custom.mjs`。

## 13. うまくいかないとき

| 困っていること | 直し方 |
|---|---|
| 画像が出ない | ファイル名が枠 ID と同じか（`.png` の前まで）。assets/custom なら `node tools/scan_custom.mjs` を実行してから開き直す。ゲーム内で入れた画像のほうが優先される |
| 背景が残る | 「許容値」を上げる。四隅の色がばらばらなら「スポイト」で背景を押す。囲まれた所は「閉じた穴も消す」 |
| 体まで消える | 「許容値」を下げる。「つながった所だけ」をオンに。白い服を白い背景で作らない（緑の背景で作り直す） |
| 縁が白い・緑っぽい | 「縁のなじませ」を 2〜3 に |
| 浮いている・地面に沈む | 「足元を自動で」。足の裏を基準点に |
| 武器が手から離れる | 体の「手」のアンカーと、武器の基準点（握る所）を合わせる。斜めの武器は「回転」 |
| 大きさが合わない | 「大きさ」で調整（透明な外側を切っていないと小さく見える） |
| 向きが逆 | 「左右反転」（敵は左向き、主人公は右向き） |
| 演出に四角い箱 | 「ほぼ黒を真っ黒に」か「黒を透明に」。背景を真っ黒で作り直す |
| 背景に継ぎ目 | 「左右をつなげる」を 5〜10% |
| コマ送りがずれる | コマ数が合っているか。全部のコマを同じ大きさで横 1 列に |
| 入れた画像が消えた | サイトのデータの削除・非公開のウィンドウでは消えます。パックを書き出しておき、読み込み直す |
| ダウンロードできない | ページの中に埋め込まれていると止められることがあります。「文字で表示」→「コピー」、型紙は「型紙を見る」から長押し／右クリックで保存 |
| 重い | 大きな画像は自動で縮めます。コマ送りのコマ数を減らす |

## 14. 作る人向け（プログラム）

- 枠の一覧は `src/render/manifest.js` の `buildManifest()` がデータ（クラス・スキル・敵・ペット・ユニーク・素材・章）から作ります。担当が枠を足すときは `addSlots([{ id, cat, label, w, h, ax, ay, ... }])`。指示文は `src/render/prompts.js`。
- 描く側: `assets.sprite(id)`（使い回し）・`assets.draw(ctx, id, x, y, { scale, rot, flip, alpha, t })`・`assets.drawFit(ctx, id, cx, cy, w, h)`（縦横比を保つ）・`assets.drawCover(...)`・`assets.isCustom(id)`（演出は差し替えがあれば画像、無ければコードの演出）・`assets.anchor(sprite, 'hand', x, y, { scale })`。
- 持ち物のアイコンの ID は `itemIconId(item)`（ユニークの専用の絵に対応）。
- 型紙: `src/render/template.js` の `renderTemplate(id)`。ツール: `tools/scan_custom.mjs`・`tools/gen_prompts.mjs`（枠を足したら実行）・`tools/export_templates.mjs`（Chromium で型紙を書き出す）。
- テスト: `node tests/assets.mjs`（枠とデータの対応・指示文・画素の計算・ツール）、`node tests/smoke.mjs --only=assets`（ブラウザで取り込み・調整・保存・パック）。
